**Literal:** Rises this one with vision, the one king  
**Faithful:** Here rises the one with vision, the sole king,  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`udet'ayañ-`** | `(sandhi)` [*udeti* (3rd sg pres act indic) + *ayaṁ* (dem pron masc nom sg); *-i* elided, *ayañ* before *c-*] rises, this one; **[udeti (ud + √i + e + ti) + ayaṁ]** |
| **`cakkhumā`** | `(adj masc nom sg)` one with vision, who can see; **[√cakkh + u + mant]** |
| **`eka-rājā`** | `(masc nom sg comp)` sole king; **[eka + rāja]** |
| ↳ **`eka`** | `(card comp)` one, sole; **[eka]** |
| ↳ **`rājā`** | `(masc nom sg)` king; **[√rāj + a]** |
