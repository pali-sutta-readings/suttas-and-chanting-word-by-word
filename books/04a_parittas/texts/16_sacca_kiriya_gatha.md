# Sacca-kiriyā-gāthā

*Verses of the Act of Truth*

**Natthi me saraṇaṁ aññaṁ buddho me saraṇaṁ varaṁ**

**Literal:** There is not for me refuge other; [the] Buddha [is] my refuge excellent  
**Faithful:** I have no other refuge; the Buddha is my excellent refuge.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`natthi`** | `(3rd sg pres act indic)` [*na* + *atthi*] there is not; **[na + √as + ti]** |
| **`me`** | `(1st sg dat/gen)` for me, my; **[ahaṁ]** |
| **`saraṇaṁ`** | `(nt nom sg)` refuge; **[√sar + aṇa]** |
| **`aññaṁ`** | `(pron nt nom sg)` other, another; **[añña]** |
| **`buddho`** | `(masc nom sg)` Buddha, Awakened One; **[√budh + ta]** |
| **`me`** | `(1st sg gen)` my; **[ahaṁ]** |
| **`saraṇaṁ`** | `(nt nom sg)` refuge; **[√sar + aṇa]** |
| **`varaṁ`** | `(nt nom sg)` excellent, best; **[√var + a]** |

**Etena sacca-vajjena sotthi te/me hotu sabbadā**

**Literal:** By this truth-speaking safety for you/me may be always.  
**Faithful:** By the speaking of this truth, may you/I be safe at all times.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`etena`** | `(dem pron nt instr sg)` by this; **[eta]** |
| **`sacca-vajjena`** | `(nt instr sg comp)` by the speaking of truth, by a declaration of truth; **[sacca + vajja]** |
| ↳ **`sacca`** | `(nt comp)` truth; **[sat + ya (√as)]** |
| ↳ **`vajjena`** | `(ptp nt instr sg)` speaking, what is said; **[√vad + ya]** |
| **`sotthi`** | `(fem nom sg)` safety, well-being; **[su > so + √as + ti]** |
| **`te/me`** | `(2nd sg dat)` / `(1st sg dat)` for you / for me; **[tvaṁ / ahaṁ]** |
| **`hotu`** | `(3rd sg pres act imperat)` may it be, may there be; **[√hū > ho + tu]** |
| **`sabbadā`** | `(ind)` always, at all times; **[sabba + dā]** |
