# Abhaya-paritta

*The Protection from Fear*

**Yan-dunnimittaṁ avamaṅgalañ-ca**

**Literal:** Whatever bad sign, ill omen and  
**Faithful:** Whatever bad sign or ill omen,  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`yan-`** | `(rel pron nt nom sg)` [*yaṁ* before *d-*] whatever; **[ya]** |
| **`dunnimittaṁ`** | `(nt nom sg)` bad sign, evil portent; **[du + ni + √mā > mi + tta]** |
| **`avamaṅgalañ-`** | `(nt nom sg)` [*avamaṅgalaṁ* before *c-*] ill omen, bad luck; **[ava + √maṅg + ala]** |
| **`ca`** | `(ind)` and; **[ca]** |

**Yo cāmanāpo sakuṇassa saddo**

**Literal:** which and unpleasant of a bird sound,  
**Faithful:** whatever unpleasant cry of a bird,  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`yo`** | `(rel pron masc nom sg)` which, whatever; **[ya]** |
| **`cāmanāpo`** | `(sandhi)` [*ca* (ind) + *amanāpo* (adj masc nom sg)] and unpleasant; **[ca + amanāpo (na > a + manāpa)]** |
| **`sakuṇassa`** | `(masc gen sg)` of a bird; **[sakuṇa, no root in DPD]** |
| **`saddo`** | `(masc nom sg)` sound, cry; **[√sadd + a]** |

**Pāpaggaho dussupinaṁ akantaṁ**

**Literal:** evil planet, bad dream, unpleasant,  
**Faithful:** evil planet, or disagreeable bad dream:  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`pāpaggaho`** | `(masc nom sg comp)` evil planet, malign planetary influence; **[pāpa + gaha]** |
| ↳ **`pāpa`** | `(adj comp)` evil, bad; **[pāpa, no root in DPD]** |
| ↳ **`ggaho`** | `(masc nom sg)` [*gaho* with doubled *g* in the compound] planet, seizer; **[√gah + a]** |
| **`dussupinaṁ`** | `(nt nom sg)` bad dream, nightmare; **[du + √sup + ina]** |
| **`akantaṁ`** | `(pp nt nom sg)` unpleasant, disagreeable; **[na > a + √kam + ta]** |

**Buddhānubhāvena vināsamentu**

**Literal:** by [the] Buddha-power to destruction may they go.  
**Faithful:** by the power of the Buddha, may they come to nothing.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`buddhānubhāvena`** | `(masc instr sg comp)` by the power of the Buddha; **[buddha + anubhāva]** |
| ↳ **`buddha`** | `(masc comp)` Buddha; **[√budh + ta]** |
| ↳ **`ānubhāvena`** | `(masc instr sg)` by the power, by the might; **[anu > ānu + √bhū > bhāv + a]** |
| **`vināsamentu`** | `(sandhi)` [*vināsaṁ* (masc acc sg) + *entu* (3rd pl pres act imperat)] may they go to destruction; **[vināsaṁ (vi + √nas + a) + entu (√i + e + ntu)]** |
