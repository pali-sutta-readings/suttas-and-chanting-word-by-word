# Abhiṇha-paccavekkhaṇa-pāṭha

*Five Subjects for Frequent Recollection*

**Handa mayaṁ abhiṇha-paccavekkhaṇa-pāṭhaṁ bhaṇāmase**

**Literal:** Come now, we [the] frequent-reflection-passage let us recite  
**Faithful:** Now let us recite the passage for frequent reflection.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`handa`** | `(interj)` come now, well then; **[handa]** |
| **`mayaṁ`** | `(1st pl nom)` we; **[ahaṁ]** |
| **`abhiṇha-paccavekkhaṇa-pāṭhaṁ`** | `(masc acc sg comp)` passage for frequent reflection; **[abhiṇha + paccavekkhaṇa + pāṭha]** |
| ↳ **`abhiṇha`** | `(adj comp)` frequent, regular; **[abhi + √ikkh + aṇa > abhikkhaṇa > abhiṇha]** |
| ↳ **`paccavekkhaṇa`** | `(nt comp)` reviewing, reflection; **[pati + ava + √ikkh + aṇa]** |
| ↳ **`pāṭhaṁ`** | `(masc acc sg)` passage, text for recitation; **[√paṭh > pāṭh + a]** |
| **`bhaṇāmase`** | `(1st pl pres mid imperat)` let us recite, let us say; **[√bhaṇ + a + mase]** |

**Sabbehi me piyehi manāpehi nānābhāvo vinābhāvo**

**Literal:** With all to me dear [and] pleasing [there is] separation, parting  
**Faithful:** From all that is dear and pleasing to me there is separation and parting.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`sabbehi`** | `(pron masc/nt instr pl)` with all, from all; **[sabba]** |
| **`me`** | `(1st sg dat/gen)` to me; **[ahaṁ]** |
| **`piyehi`** | `(masc/nt instr pl)` dear, beloved; **[√pī > piy + a]** |
| **`manāpehi`** | `(masc/nt instr pl)` pleasing, agreeable; **[manāpa, no root in DPD]** |
| **`nānābhāvo`** | `(masc nom sg comp)` separation, becoming apart; **[nānā + bhāva]** |
| ↳ **`nānā`** | `(ind comp)` apart, various; **[nānā]** |
| ↳ **`bhāvo`** | `(masc nom sg)` state, becoming; **[√bhū > bhāv + a]** |
| **`vinābhāvo`** | `(masc nom sg comp)` parting, being without; **[vinā + bhāva]** |
| ↳ **`vinā`** | `(ind comp)` without, apart from; **[vi + nā]** |
| ↳ **`bhāvo`** | `(masc nom sg)` state, becoming; **[√bhū > bhāv + a]** |

**Kammassakomhi kammadāyādo kammayoni kammabandhu kammapaṭisaraṇo**

**Literal:** Kamma-owner I am, kamma-heir, kamma-womb, kamma-kinsman, kamma-refuge  
**Faithful:** My kamma is my own; I am heir to my kamma, born of kamma, bound to kamma, with kamma as my refuge.

| :--- | :--- |

| ↳ **`kamma`** | `(nt comp)` kamma, action; **[√kar + ma]** |
| ↳ **`sakomhi`** | `(masc nom sg)` [*sako* (with the *s* doubled after *kamma*) + *amhi* (1st sg pres act indic)] own, owner; I am; **[sa + ka; + amhi]** |
| **`kammadāyādo`** | `(masc nom sg comp)` heir to kamma; **[kamma + dāyāda]** |
| ↳ **`kamma`** | `(nt comp)` kamma, action; **[√kar + ma]** |
| ↳ **`dāyādo`** | `(masc nom sg)` heir; **[dāya + āda]** |
| **`kammayoni`** | `(masc nom sg comp)` having kamma as womb, born of kamma; **[kamma + yoni]** |
| ↳ **`kamma`** | `(nt comp)` kamma, action; **[√kar + ma]** |
| ↳ **`yoni`** | `(masc nom sg)` [fem noun *yoni* ending an adjectival compound] womb, origin; **[√yu > yo + ni]** |
| **`kammabandhu`** | `(masc nom sg comp)` having kamma as kinsman, bound to kamma; **[kamma + bandhu]** |
| ↳ **`kamma`** | `(nt comp)` kamma, action; **[√kar + ma]** |
| ↳ **`bandhu`** | `(masc nom sg)` kinsman, relative; **[√bandh + u]** |

| ↳ **`kamma`** | `(nt comp)` kamma, action; **[√kar + ma]** |
| ↳ **`paṭisaraṇo`** | `(masc nom sg)` [nt noun *paṭisaraṇa* ending an adjectival compound] refuge, support; **[pati + √sar + aṇa]** |

**Yaṁ kammaṁ karissāmi, kalyāṇaṁ vā pāpakaṁ vā, tassa dāyādo bhavissāmi**

**Literal:** Which kamma I will do, good or bad or, of that heir I will be  
**Faithful:** Whatever kamma I do, whether good or bad, I will be its heir.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`yaṁ`** | `(rel pron nt acc sg)` which, whatever; **[ya]** |
| **`kammaṁ`** | `(nt acc sg)` kamma, action; **[√kar + ma]** |
| **`karissāmi`** | `(1st sg fut act indic)` I will do; **[√kar + issa + mi]** |
| **`kalyāṇaṁ`** | `(nt acc sg)` good, beneficial; **[kalyāṇa, no root in DPD]** |
| **`vā`** | `(ind)` or; **[vā]** |
| **`pāpakaṁ`** | `(nt acc sg)` bad, evil; **[pāpa + ka]** |
| **`vā`** | `(ind)` or; **[vā]** |
| **`tassa`** | `(dem pron nt gen sg)` of that; **[ta]** |
| **`dāyādo`** | `(masc nom sg)` heir; **[dāya + āda]** |
| **`bhavissāmi`** | `(1st sg fut act indic)` I will be; **[√bhū + a + issa > bhavissa + mi]** |

**Evaṁ amhehi abhiṇhaṁ paccavekkhitabbaṁ**

**Faithful:** This is how we should reflect again and again.  

| Word | Analysis & Meaning |
