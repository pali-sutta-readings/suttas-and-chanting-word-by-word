# Atīta-paccavekkhaṇa-pāṭha

*Recollection After Using the Requisites*

**Handa mayaṁ atīta-paccavekkhaṇa-pāṭhaṁ bhaṇāmase**

**Literal:** Come now, we [the] past-reflection-passage let us recite  
**Faithful:** Now let us recite the passage for reflecting on what has passed.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`handa`** | `(interj)` come now, well then; **[handa]** |
| **`mayaṁ`** | `(1st pl nom)` we; **[ahaṁ]** |
| **`atīta-paccavekkhaṇa-pāṭhaṁ`** | `(masc acc sg comp)` passage for reflecting on what has passed; **[atīta + paccavekkhaṇa + pāṭha]** |
| ↳ **`atīta`** | `(pp comp)` past, what has passed; **[ati + √i + ta]** |
| ↳ **`paccavekkhaṇa`** | `(nt comp)` reviewing, reflection; **[pati + ava + √ikkh + aṇa]** |
| ↳ **`pāṭhaṁ`** | `(masc acc sg)` passage, text for recitation; **[√paṭh > pāṭh + a]** |
| **`bhaṇāmase`** | `(1st pl pres mid imperat)` let us recite, let us say; **[√bhaṇ + a + mase]** |
