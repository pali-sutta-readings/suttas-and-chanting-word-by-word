**Handa mayaṁ ariyaṭṭhaṅgika-magga-pāṭhaṁ bhaṇāmase**

**Literal:** Come now, we [the] noble-eightfold-path-passage let us recite  
**Faithful:** Come now, let us recite the passage on the noble eightfold path.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`handa`** | `(interj)` come now, well then; **[handa]** |
| **`mayaṁ`** | `(1st pl nom)` we; **[ahaṁ]** |
| **`ariyaṭṭhaṅgika-magga-pāṭhaṁ`** | `(masc acc sg comp)` passage on the noble eightfold path; **[ariya + aṭṭhaṅgika + magga + pāṭha]** |
| ↳ **`ariy'`** | `(adj comp)` [*ariya* before a vowel] noble; **[ariya, no root in DPD]** |
| ↳ **`aṭṭhaṅgika`** | `(adj comp)` eightfold, having eight factors; **[aṭṭha + aṅgika]** |
| ↳ **`magga`** | `(masc comp)` path, way; **[√magg + a]** |
| ↳ **`pāṭhaṁ`** | `(masc acc sg)` passage, text for recitation; **[√paṭh > pāṭh + a]** |
| **`bhaṇāmase`** | `(1st pl pres mid imperat)` let us recite, let us say; **[√bhaṇ + a + mase]** |
