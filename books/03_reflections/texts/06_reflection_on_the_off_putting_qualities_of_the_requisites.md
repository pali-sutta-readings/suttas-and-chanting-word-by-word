# Dhātu-paṭikūla-paccavekkhaṇa-pāṭha

*Reflection on the Off-Putting Qualities of the Requisites*

**Handa mayaṁ dhātu-paṭikūla-paccavekkhaṇa-pāṭhaṁ bhaṇāmase**

**Literal:** Come now, we [the] element-repulsiveness-reflection-passage let us recite  
**Faithful:** Now let us recite the passage for reflecting on elements and repulsiveness.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`handa`** | `(interj)` come now, well then; **[handa]** |
| **`mayaṁ`** | `(1st pl nom)` we; **[ahaṁ]** |
| **`dhātu-paṭikūla-paccavekkhaṇa-pāṭhaṁ`** | `(masc acc sg comp)` passage for reflecting on elements and repulsiveness; **[dhātu + paṭikūla + paccavekkhaṇa + pāṭha]** |
| ↳ **`dhātu`** | `(fem comp)` element; **[√dhā + tu]** |
| ↳ **`paṭikūla`** | `(adj comp)` repulsive, disagreeable; **[pati + √kūl + a]** |
| ↳ **`paccavekkhaṇa`** | `(nt comp)` reviewing, reflection; **[pati + ava + √ikkh + aṇa]** |
| ↳ **`pāṭhaṁ`** | `(masc acc sg)` passage, text for recitation; **[√paṭh > pāṭh + a]** |
| **`bhaṇāmase`** | `(1st pl pres mid imperat)` let us recite, let us say; **[√bhaṇ + a + mase]** |
