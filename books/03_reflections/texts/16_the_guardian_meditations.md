# Catur'ārakkhā-kammaṭṭhāna-pāṭha

*The Guardian Meditations*

**Handa mayaṁ catur'ārakkhā-kammaṭṭhāna-pāṭhaṁ bhaṇāmase**

**Literal:** Come now, we [the] four-protections-meditation-passage let us recite  
**Faithful:** Come now, let us recite the passage on the four protective meditations.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`handa`** | `(interj)` come now, well then; **[handa]** |
| **`mayaṁ`** | `(1st pl nom)` we; **[ahaṁ]** |
| **`catur'ārakkhā-kammaṭṭhāna-pāṭhaṁ`** | `(masc acc sg comp)` passage on the four protective meditations; **[catur + ārakkhā + kammaṭṭhāna + pāṭha]** |
| ↳ **`catur'`** | `(card comp)` four; **[catu]** |
| ↳ **`ārakkhā`** | `(fem comp)` protection, safeguard; **[ā + √rakkh + a]** |
| ↳ **`kammaṭṭhāna`** | `(nt comp)` meditation theme, meditation subject; **[kamma + ṭhāna]** |
| ↳ **`pāṭhaṁ`** | `(masc acc sg)` passage, text for recitation; **[√paṭh > pāṭh + a]** |
| **`bhaṇāmase`** | `(1st pl pres mid imperat)` let us recite, let us say; **[√bhaṇ + a + mase]** |
