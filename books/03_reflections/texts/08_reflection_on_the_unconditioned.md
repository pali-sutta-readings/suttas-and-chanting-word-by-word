# Nibbāna-sutta-pāṭha

*Reflection on the Unconditioned*

**Handa mayaṁ nibbāna-sutta-pāṭhaṁ bhaṇāmase**

**Literal:** Come now, we [the] Nibbāna-discourse-passage let us recite  
**Faithful:** Now let us recite the passage from the discourse on Nibbāna.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`handa`** | `(interj)` come now, well then; **[handa]** |
| **`mayaṁ`** | `(1st pl nom)` we; **[ahaṁ]** |
| **`nibbāna-sutta-pāṭhaṁ`** | `(masc acc sg comp)` passage from the discourse on Nibbāna; **[nibbāna + sutta + pāṭha]** |
| ↳ **`nibbāna`** | `(nt comp)` Nibbāna, extinguishing; **[nī + √vā > bā + ana]** |
| ↳ **`sutta`** | `(nt comp)` discourse; **[√siv > suv + ta]** |
| ↳ **`pāṭhaṁ`** | `(masc acc sg)` passage, text for recitation; **[√paṭh > pāṭh + a]** |
| **`bhaṇāmase`** | `(1st pl pres mid imperat)` let us recite, let us say; **[√bhaṇ + a + mase]** |

**Atthi bhikkhave ajātaṁ abhūtaṁ akataṁ asaṅkhataṁ**

**Literal:** There is, bhikkhus, [an] unborn, unbecome, unmade, unconditioned  
**Faithful:** Bhikkhus, there is an unborn, an unbecome, an unmade, an unconditioned.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`atthi`** | `(3rd sg pres act indic)` there is; **[√as + ti]** |
| **`bhikkhave`** | `(masc voc pl)` bhikkhus, monks; **[√bhikkh + u + ave]** |
| **`ajātaṁ`** | `(pp nt nom sg)` unborn; **[na > a + √jan > jā + ta]** |
| **`abhūtaṁ`** | `(pp nt nom sg)` unbecome, not come to be; **[na > a + √bhū + ta]** |
| **`akataṁ`** | `(pp nt nom sg)` unmade, not created; **[na > a + √kar + ta]** |
| **`asaṅkhataṁ`** | `(pp nt nom sg)` unconditioned, unconstructed; **[na > a + saṁ + √kar > khar + ta]** |

**Na yidaṁ jātassa bhūtassa katassa saṅkhatassa nissaraṇaṁ paññāyetha**

**Literal:** Not here of [the] born, become, made, conditioned [an] escape would be discerned  
**Faithful:** no escape would be discerned here from what is born, become, made and conditioned.

| :--- | :--- |
| **`na`** | `(ind)` not; **[na]** |
| **`yidaṁ`** | `(sandhi)` [*idaṁ* with *y-* inserted after *na*] here, in this case; **[y + idaṁ]** |
| **`jātassa`** | `(pp nt gen sg)` of what is born; **[√jan > jā + ta]** |
| **`bhūtassa`** | `(pp nt gen sg)` of what has become; **[√bhū + ta]** |
| **`katassa`** | `(pp nt gen sg)` of what is made; **[√kar + ta]** |

| **`nissaraṇaṁ`** | `(nt nom sg)` escape, way out; **[nī + √sar + aṇa]** |
| **`paññāyetha`** | `(3rd sg mid opt)` would be discerned, would be evident; **[pa + √ñā + ya + etha]** |
