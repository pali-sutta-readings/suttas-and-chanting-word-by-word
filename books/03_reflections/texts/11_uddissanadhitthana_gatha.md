# Uddissanādhiṭṭhāna-gāthā

*Verses of Dedication and Resolve*

**Handa mayaṁ uddissanādhiṭṭhāna-gāthāyo bhaṇāmase**

**Literal:** Come now, we [the] dedication-resolve-verses let us recite  
**Faithful:** Now let us recite the verses of dedication and resolve.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`handa`** | `(interj)` come now, well then; **[handa]** |
| **`mayaṁ`** | `(1st pl nom)` we; **[ahaṁ]** |
| **`uddissanādhiṭṭhāna-gāthāyo`** | `(fem acc pl comp)` verses of dedication and resolve; **[uddissana + adhiṭṭhāna + gāthā]** |
| ↳ **`uddissana`** | `(nt comp)` dedicating, designating [merit]; **[ud + √dis + ana]** |
| ↳ **`adhiṭṭhāna`** | `(nt comp)` resolve, determination; **[adhi + √ṭhā + ana]** |
| ↳ **`gāthāyo`** | `(fem acc pl)` verses; **[√gā + thā]** |
| **`bhaṇāmase`** | `(1st pl pres mid imperat)` let us recite, let us say; **[√bhaṇ + a + mase]** |
