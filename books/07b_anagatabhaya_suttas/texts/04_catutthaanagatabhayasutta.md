# Catuttha-anāgatabhaya-sutta

*The Fourth Discourse on Future Dangers*

**Pañcimāni, bhikkhave, anāgatabhayāni etarahi asamuppannāni āyatiṁ samuppajjissanti.**

**Literal:** These five, bhikkhus, future dangers, now not arisen, in the future will arise.  
**Faithful:** Bhikkhus, these five future dangers, not arisen now, will arise in the future.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`pañcimāni`** | `(sandhi)` [*pañca* (card nt nom pl) + *imāni* (dem pron nt nom pl)] these five; **[pañca; ima]** |
| **`bhikkhave`** | `(masc voc pl)` bhikkhus, monks; **[√bhikkh + u + ave]** |
| **`anāgatabhayāni`** | `(nt nom pl comp)` future dangers; **[anāgata + bhaya]** |
| ↳ **`anāgata`** | `(pp comp)` future, not yet come; **[na > an + ā + √gam + ta]** |
| ↳ **`bhayāni`** | `(nt nom pl)` dangers, perils; **[√bhī > bhay + a]** |
| **`etarahi`** | `(ind)` now, at present; **[eta + [r] + ahi]** |
| **`asamuppannāni`** | `(pp nt nom pl)` not arisen, not yet appeared; **[na > a + saṁ + ud + √pad + na]** |
| **`āyatiṁ`** | `(ind)` in the future, in time to come; **[ā + √yat + i + iṁ]** |
| **`samuppajjissanti`** | `(3rd pl fut act indic)` will arise, will appear; **[saṁ + ud + √pad + ya > pajja + issa + nti]** |
