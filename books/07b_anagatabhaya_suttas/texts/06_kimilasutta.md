# Kimila-sutta

*The Discourse to Kimila*

**Evaṁ me sutaṁ**

**Literal:** Thus by me heard.  
**Faithful:** Thus have I heard.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`evaṁ`** | `(ind)` thus, in this way; **[eva + aṁ]** |
| **`me`** | `(1st sg instr)` by me; **[ahaṁ]** |
| **`sutaṁ`** | `(pp nt nom sg)` heard; **[√su + ta]** |

**ekaṁ samayaṁ bhagavā kimilāyaṁ viharati niculavane.**

**Literal:** one time the Blessed One at Kimilā dwells, in the Nicula Grove.  
**Faithful:** On one occasion the Blessed One was staying at Kimilā, in the Nicula Grove.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`ekaṁ`** | `(card masc acc sg)` one; **[eka]** |
| **`samayaṁ`** | `(masc acc sg)` [accusative of time] time, occasion; **[saṁ + √i > ay + a]** |
| **`bhagavā`** | `(masc nom sg)` the Blessed One; **[√bhaj > bhag + a + vant]** |
| **`kimilāyaṁ`** | `(fem loc sg)` at Kimilā, a town; **[kimilā, no root in DPD]** |
| **`viharati`** | `(3rd sg pres act indic)` [historic present] dwells, was staying; **[vi + √har + a + ti]** |
| **`niculavane`** | `(nt loc sg comp)` in the Nicula Grove; **[nicula + vana]** |
| ↳ **`nicula`** | `(masc comp)` the nicula tree (Barringtonia acutangula); **[nicula, no root in DPD]** |
| ↳ **`vane`** | `(nt loc sg)` grove, wood; **[vana, no root in DPD]** |

**Atha kho āyasmā kimilo yena bhagavā tenupasaṅkami;**

**Literal:** Then indeed the venerable Kimila, where the Blessed One [was], there approached;  
**Faithful:** Then indeed the venerable Kimila went to the Blessed One;  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`atha`** | `(ind)` then; **[atha]** |
| **`kho`** | `(ind)` indeed; **[kho]** |
| **`āyasmā`** | `(masc nom sg)` the venerable; **[ā + √i > ay + as + mant]** |
| **`kimilo`** | `(masc nom sg)` Kimila, an arahant monk; **[kimila, no root in DPD]** |
| **`yena`** | `(rel pron masc instr sg)` [with *tena*: to where] by which, where; **[ya]** |
| **`bhagavā`** | `(masc nom sg)` the Blessed One; **[√bhaj > bhag + a + vant]** |
| **`tenupasaṅkami`** | `(sandhi)` [*tena* (dem pron masc instr sg) + *upasaṅkami* (3rd sg aor act indic); with *yena*: went to where] there approached; **[ta; upa + saṁ + √kam + i]** |

**yena tathāgate parinibbute saddhammo na ciraṭṭhitiko hotī'ti?**

**Literal:** by which, the Tathāgata having attained final Nibbāna, the true Dhamma not long-lasting is?"  
**Faithful:** why, when the Tathāgata has attained final Nibbāna, the true Dhamma does not last long?"  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`yena`** | `(rel pron masc instr sg)` by which, why; **[ya]** |
| **`tathāgate`** | `(masc loc sg comp)` [locative absolute with *parinibbute*] the Tathāgata, the one thus gone; **[tathā + gata]** |
| ↳ **`tathā`** | `(ind comp)` thus, so; **[ta + thā]** |
| ↳ **`gate`** | `(masc loc sg)` gone; **[√gam + ta]** |
| **`parinibbute`** | `(pp masc loc sg)` [locative absolute] having attained final Nibbāna; **[pari + nī + √vā > vu > bu + ta]** |
| **`saddhammo`** | `(masc nom sg comp)` the true Dhamma; **[sat + dhamma]** |
| ↳ **`sad`** | `(ind comp)` [*sat* before a voiced consonant] true, good, real; **[√as + a > sa + nta > sat]** |
| ↳ **`dhammo`** | `(masc nom sg)` Dhamma, teaching; **[√dhar + ma]** |
| **`na`** | `(ind)` not; **[na]** |
| **`ciraṭṭhitiko`** | `(adj masc nom sg comp)` long-lasting, enduring; **[cira + ṭhitika]** |
| ↳ **`cira`** | `(adj comp)` long (of time); **[cira, no root in DPD]** |
| ↳ **`ṭṭhitiko`** | `(adj masc nom sg)` lasting, enduring; **[√ṭhā + ti + ka]** |
| **`hotī'ti`** | `(3rd sg pres act indic)` [*hoti* + *iti* (ind), closing the question] is; **[√hū > ho + ti]** |
