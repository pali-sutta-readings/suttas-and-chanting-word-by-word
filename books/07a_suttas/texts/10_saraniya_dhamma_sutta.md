**Ekaṁ samayaṁ Bhagavā, Sāvatthiyaṁ viharati, Jetavane Anāthapiṇḍikassa, ārāme.**

**Literal:** One time the Blessed One at Sāvatthī dwells, in Jeta's Grove, Anāthapiṇḍika's, in the park.  
**Faithful:** On one occasion the Blessed One was staying near Sāvatthī, in Jeta's Grove, Anāthapiṇḍika's monastery.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`ekaṁ`** | `(card masc acc sg)` one; **[eka]** |
| **`samayaṁ`** | `(masc acc sg)` [accusative of time] time, occasion; **[saṁ + √i > ay + a]** |
| **`bhagavā`** | `(masc nom sg)` the Blessed One; **[√bhaj > bhag + a + vant]** |
| **`sāvatthiyaṁ`** | `(fem loc sg)` at Sāvatthī, near Sāvatthī; **[√su > sāv + a + ttha + ī]** |
| **`viharati`** | `(3rd sg pres act indic)` [historic present] dwells, was staying; **[vi + √har + a + ti]** |
| **`jetavane`** | `(nt loc sg comp)` in Jeta's Grove; **[jeta + vana]** |
| ↳ **`jeta`** | `(masc comp)` Jeta, a prince of Sāvatthī; **[√ji > je + ta]** |
| ↳ **`vane`** | `(nt loc sg)` grove, wood; **[vana, no root in DPD]** |
| **`anāthapiṇḍikassa`** | `(masc gen sg comp)` of Anāthapiṇḍika, "feeder of the helpless"; **[anātha + piṇḍika]** |
| ↳ **`anātha`** | `(adj comp)` helpless, without protector; **[na > a + √nāth + a]** |
