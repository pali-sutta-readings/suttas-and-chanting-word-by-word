# Puggalapaññatti

*The Designation of Persons*

**Cha paññattiyo khandhapaññatti, āyatanapaññatti, dhātupaññatti, saccapaññatti, indriyapaññatti, puggalapaññattī'ti.**

**Literal:** Six designations: aggregate-designation, sense-base-designation, element-designation, truth-designation, faculty-designation, person-designation, thus.  
**Faithful:** There are six designations: the designation of aggregates, of sense bases, of elements, of truths, of faculties, and of persons.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`cha`** | `(card fem nom pl)` six; **[cha]** |
| **`paññattiyo`** | `(fem nom pl)` designations, concepts; **[pa + √ñā > ñāpe + ti]** |
| **`khandhapaññatti`** | `(fem nom sg comp)` designation of the aggregates; **[khandha + paññatti]** |
| ↳ **`khandha`** | `(masc comp)` aggregate, mass; **[√khandh + a]** |
| ↳ **`paññatti`** | `(fem nom sg)` designation, concept; **[pa + √ñā > ñāpe + ti]** |
| **`āyatanapaññatti`** | `(fem nom sg comp)` designation of the sense bases; **[āyatana + paññatti]** |
| ↳ **`āyatana`** | `(nt comp)` sense base; **[ā + √yat + ana]** |
| ↳ **`paññatti`** | `(fem nom sg)` designation, concept; **[pa + √ñā > ñāpe + ti]** |
| **`dhātupaññatti`** | `(fem nom sg comp)` designation of the elements; **[dhātu + paññatti]** |
| ↳ **`dhātu`** | `(fem comp)` element, property; **[√dhā + tu]** |
