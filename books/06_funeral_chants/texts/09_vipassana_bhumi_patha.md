# Vipassanā-bhūmi-pāṭha

*The Recitation of the Grounds of Insight*

**Pañcakkhandhā:**

**Literal:** Five-aggregates:  
**Faithful:** The five aggregates:  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`pañcakkhandhā`** | `(masc nom pl comp)` the five aggregates; **[pañca + khandha]** |
| ↳ **`pañca`** | `(card comp)` five; **[pañca]** |
| ↳ **`khandhā`** | `(masc nom pl)` aggregates, masses, groups; **[√khandh + a]** |

**Rūpakkhandho, vedanākkhandho, saññākkhandho, saṅkhārakkhandho, viññāṇakkhandho.**

**Literal:** Form-aggregate, feeling-aggregate, perception-aggregate, formations-aggregate, consciousness-aggregate.  
**Faithful:** the aggregate of form, the aggregate of feeling, the aggregate of perception, the aggregate of formations, the aggregate of consciousness.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`rūpakkhandho`** | `(masc nom sg comp)` the aggregate of form; **[rūpa + khandha]** |
| ↳ **`rūpa`** | `(nt comp)` form, materiality; **[√rūp + a]** |
| ↳ **`khandho`** | `(masc nom sg)` aggregate, mass; **[√khandh + a]** |
| **`vedanākkhandho`** | `(masc nom sg comp)` the aggregate of feeling; **[vedanā + khandha]** |
| ↳ **`vedanā`** | `(fem comp)` feeling, felt experience; **[√vid > ved + anā]** |
| ↳ **`khandho`** | `(masc nom sg)` aggregate, mass; **[√khandh + a]** |
| **`saññākkhandho`** | `(masc nom sg comp)` the aggregate of perception; **[saññā + khandha]** |
| ↳ **`saññā`** | `(fem comp)` perception, recognition; **[saṁ + √ñā + ā]** |
| ↳ **`khandho`** | `(masc nom sg)` aggregate, mass; **[√khandh + a]** |
| **`saṅkhārakkhandho`** | `(masc nom sg comp)` the aggregate of (volitional) formations; **[saṅkhāra + khandha]** |
| ↳ **`saṅkhāra`** | `(masc comp)` volitional formation, mental formation; **[saṁ + √kar > khār + a]** |
| ↳ **`khandho`** | `(masc nom sg)` aggregate, mass; **[√khandh + a]** |
| **`viññāṇakkhandho`** | `(masc nom sg comp)` the aggregate of consciousness; **[viññāṇa + khandha]** |
| ↳ **`viññāṇa`** | `(nt comp)` consciousness; **[vi + √ñā + aṇa]** |
| ↳ **`khandho`** | `(masc nom sg)` aggregate, mass; **[√khandh + a]** |
