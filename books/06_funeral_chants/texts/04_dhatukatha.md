# Dhātukathā

*The Discussion of Elements*

**Saṅgaho asaṅgaho,**

**Literal:** Inclusion, non-inclusion,  
**Faithful:** Inclusion and non-inclusion;  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`saṅgaho`** | `(masc nom sg)` inclusion, grouping (under a heading); **[saṁ + √gah + a]** |
| **`asaṅgaho`** | `(masc nom sg)` non-inclusion; **[na > a + saṁ + √gah + a]** |

**saṅgahitena asaṅgahitaṁ, asaṅgahitena saṅgahitaṁ,**

**Literal:** by-the-included the-not-included, by-the-not-included the-included,  
**Faithful:** the not included by way of the included; the included by way of the not included;  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`saṅgahitena`** | `(pp nt instr sg)` by (way of) what is included; **[saṁ + √gah + ita]** |
| **`asaṅgahitaṁ`** | `(pp nt nom sg)` what is not included; **[na > a + saṁ + √gah + ita]** |
| **`asaṅgahitena`** | `(pp nt instr sg)` by (way of) what is not included; **[na > a + saṁ + √gah + ita]** |
| **`saṅgahitaṁ`** | `(pp nt nom sg)` what is included; **[saṁ + √gah + ita]** |

**saṅgahitena saṅgahitaṁ, asaṅgahitena asaṅgahitaṁ,**

**Literal:** by-the-included the-included, by-the-not-included the-not-included,  
**Faithful:** the included by way of the included; the not included by way of the not included;  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`saṅgahitena`** | `(pp nt instr sg)` by (way of) what is included; **[saṁ + √gah + ita]** |
| **`saṅgahitaṁ`** | `(pp nt nom sg)` what is included; **[saṁ + √gah + ita]** |
| **`asaṅgahitena`** | `(pp nt instr sg)` by (way of) what is not included; **[na > a + saṁ + √gah + ita]** |
| **`asaṅgahitaṁ`** | `(pp nt nom sg)` what is not included; **[na > a + saṁ + √gah + ita]** |

**sampayogo vippayogo,**

**Literal:** association, dissociation,  
**Faithful:** association and dissociation;  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`sampayogo`** | `(masc nom sg)` association, conjunction; **[saṁ + pa + √yuj > yoje > yoge + a]** |
| **`vippayogo`** | `(masc nom sg)` dissociation, separation; **[vi + pa + √yuj > yoje > yoge + a]** |

**sampayuttena vippayuttaṁ, vippayuttena sampayuttaṁ, asaṅgahitaṁ.**

**Literal:** by-the-associated the-dissociated, by-the-dissociated the-associated, the-not-included.  
**Faithful:** the dissociated by way of the associated; the associated by way of the dissociated; … the not included.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`sampayuttena`** | `(pp nt instr sg)` by (way of) what is associated; **[saṁ + pa + √yuj + ta]** |
| **`vippayuttaṁ`** | `(pp nt nom sg)` what is dissociated; **[vi + pa + √yuj + ta]** |
| **`vippayuttena`** | `(pp nt instr sg)` by (way of) what is dissociated; **[vi + pa + √yuj + ta]** |
| **`sampayuttaṁ`** | `(pp nt nom sg)` what is associated; **[saṁ + pa + √yuj + ta]** |
| **`asaṅgahitaṁ`** | `(pp nt nom sg)` [the chant closes with the last word of the list, *vippayuttena saṅgahitaṁ asaṅgahitaṁ*] what is not included; **[na > a + saṁ + √gah + ita]** |
