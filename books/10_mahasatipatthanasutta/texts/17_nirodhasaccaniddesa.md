# Nirodhasaccaniddesa

*Exposition of the Truth of Cessation*

### 4.5.3 Nirodhasaccaniddesa

*Exposition of the truth of cessation*

**Katamañca, bhikkhave, dukkhanirodhaṁ ariyasaccaṁ?**

**Literal:** What-and, bhikkhus, [is the] suffering-cessation noble-truth?  
**Faithful:** And what, bhikkhus, is the noble truth of the cessation of suffering?  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`katamañca`** | `(sandhi)` [*katamaṁ* (interr pron nt nom sg) which?, what? + *ca* (ind) and] and what?; **[katamaṁ + ca]** |
| **`bhikkhave`** | `(masc voc pl)` bhikkhus, monks; **[√bhikkh + u + ave]** |
| **`dukkhanirodhaṁ`** | `(nt nom sg comp)` [masc in DPD; here neuter, agreeing with *ariyasaccaṁ*] cessation of suffering, end of suffering; **[dukkha + nirodha]** |
| ↳ **`dukkha`** | `(nt comp)` suffering; **[√dukkh + a]** |
| ↳ **`nirodhaṁ`** | `(nt nom sg)` [masc in DPD] cessation, ending; **[ni + √rudh > rodh + a]** |
| **`ariyasaccaṁ`** | `(nt nom sg comp)` noble truth; **[ariya + sacca]** |
| ↳ **`ariya`** | `(adj comp)` noble; **[ariya, no root in DPD]** |
| ↳ **`saccaṁ`** | `(nt nom sg)` truth; **[√as > sa + nta > santa > sat + ya]** |

**Yo tassāyeva taṇhāya asesavirāganirodho cāgo paṭinissaggo mutti anālayo.**

**Literal:** Which of that very craving [is] remainderless-fading-cessation, giving up, relinquishing, release, non-attachment.  
**Faithful:** It is the remainderless fading away and cessation of that very craving, its giving up, relinquishing, release, and non-attachment.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`yo`** | `(rel pron masc nom sg)` which, that which; **[ya]** |
| **`tassāyeva`** | `(sandhi)` [*tassā* (dem pron fem gen sg) of that + *eva* (ind) just, very, with *y-* inserted] of that very; **[tassā + y + eva]** |
| **`taṇhāya`** | `(fem gen sg)` of craving; **[√tas + ṇhā]** |
| **`asesavirāganirodho`** | `(masc nom sg comp)` fading away and cessation without remainder; **[asesa + virāga + nirodha]** |
| ↳ **`asesa`** | `(adj comp)` without remainder, complete; **[na > a + √sis > ses + a]** |
| ↳ **`virāga`** | `(masc comp)` fading away, dispassion; **[vi + √raj > rag > rāg + a]** |
| ↳ **`nirodho`** | `(masc nom sg)` cessation, ending; **[ni + √rudh > rodh + a]** |
| **`cāgo`** | `(masc nom sg)` giving up, relinquishing; **[√caj > cāg + a]** |
| **`paṭinissaggo`** | `(masc nom sg)` relinquishing, letting go; **[pati + nī + √sajj > sagg + a]** |
| **`mutti`** | `(fem nom sg)` release, liberation; **[√muc + ti]** |
| **`anālayo`** | `(masc nom sg)` non-attachment, non-clinging; **[na > an + ā + √lī > lay + a]** |

**Sā kho panesā, bhikkhave, taṇhā kattha pahīyamānā pahīyati,**

**Literal:** That indeed but-this, bhikkhus, craving where being-abandoned is-abandoned,  
**Faithful:** But where, bhikkhus, is this craving abandoned when it is abandoned,
