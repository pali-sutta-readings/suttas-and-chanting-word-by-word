# Bhadd'eka-ratta-gāthā

*Verses on an Auspicious Night*

**Atītaṁ nānvāgameyya**

**Literal:** [The] past [one] should-not-run-back-to,  
**Faithful:** One should not run back to the past,  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`atītaṁ`** | `(nt acc sg)` the past, what has gone by; **[ati + √i + ta]** |
| **`nānvāgameyya`** | `(3rd sg caus act opt)` [*na* + *anvāgameyya*] should not run back to, should not revive; **[na + anu + ā + √gam + e + eyya]** |

**nappaṭikaṅkhe anāgataṁ**

**Faithful:** nor long for the future.  

| Word | Analysis & Meaning |
| :--- | :--- |

| **`anāgataṁ`** | `(pp nt acc sg)` the future, what has not yet come; **[na > an + ā + √gam + ta]** |

**Taṁ ve bhadd'eka-ratto'ti**

**Literal:** him truly 'auspicious-one-night', thus  
**Faithful:** him, truly, 'one who has an auspicious night'  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`taṁ`** | `(dem pron masc acc sg)` him, that one; **[ta]** |
| **`ve`** | `(ind)` truly, indeed; **[ve]** |
| **`bhadd'eka-ratto'ti`** | `(adj masc nom sg comp)` [+ *iti* (ind), marking the name] one who has a single auspicious night; **[bhadda + eka + ratta; + iti]** |
| ↳ **`bhadd'`** | `(adj comp)` [*bhadda* with *-a* elided before *e-*] auspicious, excellent; **[√bhad + ra]** |
| ↳ **`eka`** | `(card comp)` one, single; **[eka]** |
| ↳ **`ratto'ti`** | `(adj masc nom sg)` [*ratto* + *iti*] having a night; **[ratti + a]** |
