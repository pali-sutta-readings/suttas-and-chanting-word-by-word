# Bhāra-sutta-gāthā

*Verses on the Burden*

**Bhārā have pañcakkhandhā**

**Literal:** Burdens truly [are the] five-aggregates,  
**Faithful:** The five aggregates are truly burdens,  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`bhārā`** | `(masc nom pl)` burdens, loads; **[√bhar > bhār + a]** |
| **`have`** | `(ind)` truly, surely; **[ha + ve]** |
| **`pañcakkhandhā`** | `(masc nom pl comp)` the five aggregates; **[pañca + khandha]** |
| ↳ **`pañca`** | `(card comp)` five; **[pañca]** |
| ↳ **`khandhā`** | `(masc nom pl)` aggregates, masses; **[√khandh + a]** |

**bhāra-hāro ca puggalo**

**Literal:** burden-carrier and [is the] person.  
**Faithful:** and the carrier of the burden is the person.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`bhāra-hāro`** | `(adj masc nom sg comp)` burden-carrier, carrying the burden; **[bhāra + hāra]** |
| ↳ **`bhāra`** | `(masc comp)` burden, load; **[√bhar > bhār + a]** |
| ↳ **`hāro`** | `(adj masc nom sg)` carrying, bearing; **[√har > hār + a]** |
| **`ca`** | `(ind)` and; **[ca]** |
| **`puggalo`** | `(masc nom sg)` person, individual; **[puggala, no root in DPD]** |
