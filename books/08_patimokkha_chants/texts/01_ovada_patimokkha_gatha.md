# Ovāda-pāṭimokkha-gāthā

*Verses on the Training Code*

**Handa mayaṁ ovāda-pāṭimokkha-gāthāyo bhaṇāmase**

**Literal:** Come now, we [the] exhortation-Pāṭimokkha-verses let us recite  
**Faithful:** Now let us recite the verses of the Pāṭimokkha of exhortation.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`handa`** | `(interj)` come now, well then; **[handa]** |
| **`mayaṁ`** | `(1st pl nom)` we; **[ahaṁ]** |
| **`ovāda-pāṭimokkha-gāthāyo`** | `(fem acc pl comp)` verses of the Pāṭimokkha of exhortation; **[ovāda + pāṭimokkha + gāthā]** |
| ↳ **`ovāda`** | `(masc comp)` exhortation, advice, instruction; **[ava + √vad > vād + a]** |
| ↳ **`pāṭimokkha`** | `(masc comp)` Pāṭimokkha, code of training rules; **[pāṭimokkha, no root in DPD]** |
| ↳ **`gāthāyo`** | `(fem acc pl)` verses; **[√gā + thā]** |
| **`bhaṇāmase`** | `(1st pl pres mid imperat)` let us recite, let us say; **[√bhaṇ + a + mase]** |
