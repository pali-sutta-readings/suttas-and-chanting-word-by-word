# Ariya-dhana-gāthā

*Verses on Noble Wealth*

**Yassa saddhā tathāgate**

**Literal:** Whose faith in the Tathāgata  
**Faithful:** One whose faith in the Tathāgata  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`yassa`** | `(rel pron masc gen sg)` whose, of whom; **[ya]** |
| **`saddhā`** | `(fem nom sg)` faith, confidence; **[sad + √dhā + ā]** |
| **`tathāgate`** | `(masc loc sg comp)` in the Tathāgata; **[tathā + gata]** |
| ↳ **`tathā`** | `(ind comp)` thus, so; **[tathā]** |
| ↳ **`gate`** | `(pp masc loc sg)` gone; **[√gam + ta]** |
