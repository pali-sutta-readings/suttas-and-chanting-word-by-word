# Vikappana-paccuddharaṇa

*Relinquishing Shared Ownership*

> Before actually using the shared article, the other bhikkhu must relinquish his share. If the other bhikkhu is senior, and the article is within forearm's length:

**Imaṁ cīvaraṁ mayhaṁ santakaṁ paribhuñja vā visajjehi vā yathāpaccayaṁ vā karohi.**

**Literal:** This robe, my property, use or give-away or as-you-wish or do.  
**Faithful:** This robe of mine: you may use it, give it away, or do as you wish with it.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`imaṁ`** | `(dem pron nt acc sg)` this; **[ima]** |
| **`cīvaraṁ`** | `(nt acc sg)` robe, robe-cloth; **[cīvara, no root in DPD]** |
| **`mayhaṁ`** | `(1st sg gen)` my, mine; **[ahaṁ]** |
| **`santakaṁ`** | `(nt acc sg)` [in apposition to *cīvaraṁ*] property, possession, belongings; **[√as > sa + nta + ka]** |
| **`paribhuñja`** | `(2nd sg pres act imperat)` use, make use of; **[pari + √bhuj > bhuñja]** |
| **`vā`** | `(ind)` or; **[vā]** |
| **`visajjehi`** | `(2nd sg pres caus act imperat)` [BM's spelling; DPD gives this sense under *vissajjeti*; kept at the bhikkhu's decision, V7] give away, dispose of; **[vi + √sajj + e + hi]** |
| **`vā`** | `(ind)` or; **[vā]** |
| **`yathāpaccayaṁ`** | `(ind)` as you wish, as you like; **[yathā + paccaya + aṁ]** |
| **`vā`** | `(ind)` or; **[vā]** |
| **`karohi`** | `(2nd sg pres act imperat)` do, make; **[√kar > karo + hi]** |

**Variant:** more than one robe: *imaṁ cīvaraṁ* → *imāni cīvarāni*; *santakaṁ* → *santakāni*  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`imāni`** | `(dem pron nt acc pl)` these; **[ima]** |
| **`cīvarāni`** | `(nt acc pl)` robes, robe-cloths; **[cīvara, no root in DPD]** |
| **`santakāni`** | `(nt acc pl)` [in apposition to *cīvarāni*] properties, possessions, belongings; **[√as > sa + nta + ka]** |

**Variant:** second owner is junior: *paribhuñja* → *paribhuñjatha*; *visajjehi* → *visajjetha*; *karohi* → *karotha*  

| Word | Analysis & Meaning |
| :--- | :--- |

| Word | Analysis & Meaning |

> To rescind the shared ownership in the case when the receiving bhikkhu is absent, the witness says:

**Tesaṁ santakaṁ paribhuñja vā vissajjehi vā yathāpaccayaṁ vā karohi.**

**Literal:** Their property use or give-away or as-you-wish or do.  
**Faithful:** Use what is theirs, give it away or do as you like with it.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`tesaṁ`** | `(dem pron masc gen pl)` their, of them; **[ta]** |
| **`santakaṁ`** | `(nt acc sg)` property, possession, belongings; **[√as > sa + nta + ka]** |
| **`paribhuñja`** | `(2nd sg pres act imperat)` use, make use of; **[pari + √bhuj > bhuñja]** |
