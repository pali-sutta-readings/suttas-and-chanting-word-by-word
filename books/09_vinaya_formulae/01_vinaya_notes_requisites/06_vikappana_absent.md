# Vikappana

*Sharing Ownership: Receiving Bhikkhu is Absent*

> In the absence of the receiving bhikkhus, say to a witness:

**Imaṁ cīvaraṁ vikappanatthāya tuyhaṁ dammi.**

**Literal:** This robe for-the-purpose-of-sharing to-you [I] give.  
**Faithful:** I give this robe to you for the purpose of sharing.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`imaṁ`** | `(dem pron nt acc sg)` this; **[ima]** |
| **`cīvaraṁ`** | `(nt acc sg)` robe, robe-cloth; **[cīvara, no root in DPD]** |
| **`vikappanatthāya`** | `(masc dat sg comp)` for the purpose of sharing (ownership), for the sake of assigning ownership; **[vikappana + attha]** |
| ↳ **`vikappana`** | `(nt comp)` (vinaya) sharing ownership, assigning ownership; **[vi + √kapp + e + ana]** |
| ↳ **`atthāya`** | `(masc dat sg)` for the purpose (of), for the sake (of); **[√ar + tha]** |
| **`tuyhaṁ`** | `(2nd sg dat)` to you; **[tvaṁ]** |
| **`dammi`** | `(1st sg pres act indic)` I give; **[√dā + āmi > dammi]** |

**Variant:** to share a bowl: *imaṁ cīvaraṁ* → *imaṁ pattaṁ*  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`imaṁ`** | `(dem pron masc acc sg)` [agrees with *pattaṁ*] this; **[ima]** |
| **`pattaṁ`** | `(masc acc sg)` alms bowl, bowl; **[√pā + ta]** |

**Variant:** more than one article: *imaṁ cīvaraṁ* → *imāni cīvarāni*; *imaṁ pattaṁ* → *ime patte*  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`imāni`** | `(dem pron nt acc pl)` these; **[ima]** |
| **`cīvarāni`** | `(nt acc pl)` robes, robe-cloths; **[cīvara, no root in DPD]** |
| **`ime`** | `(dem pron masc acc pl)` these; **[ima]** |
| **`patte`** | `(masc acc pl)` alms bowls, bowls; **[√pā + ta]** |

**Variant:** article beyond forearm's length: *imaṁ* → *etaṁ*; *imāni* → *etāni*; *ime* → *ete*  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`etaṁ`** | `(dem pron nt acc sg)` / `(dem pron masc acc sg)` [nt with *cīvaraṁ*, masc with *pattaṁ*] that; **[eta]** |
| **`etāni`** | `(dem pron nt acc pl)` those; **[eta]** |
| **`ete`** | `(dem pron masc acc pl)` those; **[eta]** |

> The witness should then ask the original owner the names of two bhikkhus or novices who are his friends or acquaintances:

**Ko te mitto vā sandiṭṭho vā.**

**Literal:** Who [is] your friend or acquaintance or?  
**Faithful:** Who is your friend or acquaintance?  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`ko`** | `(interr pron masc nom sg)` who?; **[ka]** |
| **`te`** | `(2nd sg gen)` your, of you; **[tvaṁ]** |
| **`mitto`** | `(masc nom sg)` friend; **[√mitt + a]** |
| **`vā`** | `(ind)` or; **[vā]** |
| **`sandiṭṭho`** | `(masc nom sg)` acquaintance, friend; **[saṁ + √dis + ta]** |
| **`vā`** | `(ind)` or; **[vā]** |

> The original owner tells their names, e.g.:

**Uttaro bhikkhu ca tisso sāmaṇero ca.**

**Literal:** Uttaro [the] bhikkhu and Tisso [the] novice and.  
**Faithful:** Bhikkhu Uttaro and Sāmaṇera Tisso.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`uttaro`** | `(masc nom sg)` [example name; substitute the actual name] Uttaro; **[proper name]** |
| **`bhikkhu`** | `(masc nom sg)` [in apposition to *uttaro*] bhikkhu, monk; **[√bhikkh + u]** |
| **`ca`** | `(ind)` and; **[ca]** |
| **`tisso`** | `(masc nom sg)` [example name; substitute the actual name] Tisso; **[proper name]** |
| **`sāmaṇero`** | `(masc nom sg)` [in apposition to *tisso*] novice, sāmaṇera; **[√sam > sām + aṇa + era]** |
| **`ca`** | `(ind)` and; **[ca]** |

> The witness then says:

**Ahaṁ tesaṁ dammi.**

**Literal:** I to-them give.  
**Faithful:** I give it to them.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`ahaṁ`** | `(1st sg nom)` I; **[ahaṁ]** |
| **`tesaṁ`** | `(dem pron masc dat pl)` to them; **[ta]** |
| **`dammi`** | `(1st sg pres act indic)` I give; **[√dā + āmi > dammi]** |

> Or the witness says:

**Ahaṁ uttarassa bhikkhuno ca tissassa sāmaṇerassa dammi.**

**Literal:** I to Uttaro [the] bhikkhu and to Tisso [the] novice give.  
**Faithful:** I give it to Bhikkhu Uttaro and Sāmaṇera Tisso.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`ahaṁ`** | `(1st sg nom)` I; **[ahaṁ]** |
| **`uttarassa`** | `(masc dat sg)` [example name; substitute the actual name] to Uttaro; **[proper name]** |
| **`bhikkhuno`** | `(masc dat sg)` [in apposition to *uttarassa*] to the bhikkhu, to the monk; **[√bhikkh + u]** |
| **`ca`** | `(ind)` and; **[ca]** |
| **`tissassa`** | `(masc dat sg)` [example name; substitute the actual name] to Tisso; **[proper name]** |
| **`sāmaṇerassa`** | `(masc dat sg)` [in apposition to *tissassa*] to the novice, to the sāmaṇera; **[√sam > sām + aṇa + era]** |
| **`dammi`** | `(1st sg pres act indic)` I give; **[√dā + āmi > dammi]** |
