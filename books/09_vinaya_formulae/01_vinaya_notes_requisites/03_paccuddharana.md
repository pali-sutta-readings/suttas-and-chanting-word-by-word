# Paccuddharaṇa

*Relinquishing*

> When an outer robe, upper robe, lower robe, alms bowl or sitting-cloth is to be replaced, the article already determined must first be relinquished from use:

**Imaṁ saṅghāṭiṁ paccuddharāmi.**

**Literal:** This outer-robe [I] relinquish.  
**Faithful:** I relinquish this outer robe.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`imaṁ`** | `(dem pron fem acc sg)` this; **[ima]** |
| **`saṅghāṭiṁ`** | `(fem acc sg)` outer robe, double robe; **[saṁ + √ghaṭ > ghāṭ + i]** |
| **`paccuddharāmi`** | `(1st sg pres act indic)` I relinquish, I formally give up (from use); **[pati > paty > pacc + ud + √dhar + a + mi]** |

**Variant:** upper robe: *imaṁ saṅghāṭiṁ* → *imaṁ uttarā-saṅgaṁ*  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`imaṁ`** | `(dem pron masc acc sg)` [agrees with *uttarā-saṅgaṁ*] this; **[ima]** |

| ↳ **`uttara`** | `(adj comp)` upper, higher; **[ud + tara]** |
| ↳ **`āsaṅgaṁ`** | `(masc acc sg)` robe, cloak; **[ā + √sañj > saṅg + a]** |
