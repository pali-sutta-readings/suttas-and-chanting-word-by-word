# Desanā

*Requesting Permission to Speak on Dhamma*

> After bowing three times, with hands joined in añjali, addressing the senior bhikkhu:

**Okāsaṁ me bhante thero detu dhamma-kathaṁ kathetuṁ.**

**Literal:** Opportunity to me, venerable sir, [the] elder may give, [a] Dhamma-talk to speak.  
**Faithful:** Ven. sir, please give permission to speak on Dhamma.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`okāsaṁ`** | `(masc acc sg)` opportunity, permission, leave; **[ava + √kās + a]** |
| **`me`** | `(1st sg dat)` to me, for me; **[ahaṁ]** |
| **`bhante`** | `(masc voc sg)` venerable sir; **[√bhū > bhava + nta + e]** |
| **`thero`** | `(masc nom sg)` [3rd person as polite address] the elder; **[√ṭhā > thā + ira > thera]** |
| **`detu`** | `(3rd sg pres act imperat)` may he give, please give; **[√dā > de + tu]** |
| **`dhamma-kathaṁ`** | `(fem acc sg comp)` talk on Dhamma; **[dhamma + kathā]** |
| ↳ **`dhamma`** | `(masc comp)` Dhamma, teaching; **[√dhar + ma]** |
| ↳ **`kathaṁ`** | `(fem acc sg)` talk, speech; **[√kath + ā]** |
| **`kathetuṁ`** | `(inf)` to speak, to give (a talk); **[√kath + e + tuṁ]** |

**Namo tassa bhagavato arahato sammāsambuddhassa (×3)**

**Literal:** Homage to that Blessed One, Arahant, Perfectly Self-Awakened One  
**Faithful:** Homage to the Blessed One, the Arahant, the Perfectly Self-Awakened One.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`namo`** | `(ind)` homage, reverence (to); **[√nam + as + o]** |
| **`tassa`** | `(dem pron masc dat sg)` to that, to him; **[ta]** |
| **`bhagavato`** | `(masc dat sg)` to the Blessed One; **[√bhaj > bhag + a + vant]** |
| **`arahato`** | `(masc dat sg)` to the Arahant, to the Worthy One; **[√arah + ant]** |
| **`sammāsambuddhassa`** | `(masc dat sg comp)` to the Perfectly Self-Awakened One; **[sammā + sambuddha]** |
| ↳ **`sammā`** | `(ind comp)` perfectly, rightly; **[sammā]** |
| ↳ **`sambuddhassa`** | `(masc dat sg)` to the self-awakened one; **[saṁ + √budh + ta]** |

**Buddhaṁ Dhammaṁ Saṅghaṁ namassāmi.**

**Literal:** [The] Buddha, [the] Dhamma, [the] Saṅgha I revere.  
**Faithful:** I pay homage to the Buddha, the Dhamma and the Saṅgha.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`buddhaṁ`** | `(masc acc sg)` Buddha, Awakened One; **[√budh + ta]** |
| **`dhammaṁ`** | `(masc acc sg)` Dhamma, teaching; **[√dhar + ma]** |
| **`saṅghaṁ`** | `(masc acc sg)` Saṅgha, community; **[saṁ + √ghaṭ + a]** |
| **`namassāmi`** | `(1st sg pres act indic)` I revere, I venerate, I pay homage to; **[√namass + a + mi]** |

> One may recite a sutta quote before beginning the talk, such as:

**Apārutā tesaṁ amatassa dvārā**

**Literal:** Opened [are] for them of [the] Deathless [the] doors;  
**Faithful:** Open are the doors to the Deathless.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`apārutā`** | `(pp nt nom pl)` [agrees with *dvārā*] opened, open; **[apa + ā + √var > vur > ruv + ta]** |
| **`tesaṁ`** | `(dem pron masc dat pl)` for them; **[ta]** |
| **`amatassa`** | `(nt gen sg)` of the Deathless (Nibbāna), of the deathless state; **[na > a + √mar + ta]** |
| **`dvārā`** | `(nt nom pl)` doors, gates; **[√dvar > dvār + a]** |

**ye sotavantā pamuñcantu saddhaṁ.**

**Literal:** those who [are] having ears, may [they] release faith.  
**Faithful:** May all those who have ears release their faith.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`ye`** | `(rel pron masc nom pl)` those who, who; **[ya]** |
| **`sotavantā`** | `(adj masc nom pl)` having ears, able to hear; **[√su > so + ta + vant]** |
| **`pamuñcantu`** | `(3rd pl pres act imperat)` may they release, let them set free; **[pa + √muc > muñca + ntu]** |
| **`saddhaṁ`** | `(fem acc sg)` faith, confidence; **[sad + √dhā + ā]** |

*SN 6.1; MN 26; Kd 1:5.12*

**Ito paraṁ sakkaccaṁ dhammo sotabbo'ti.**

**Literal:** From this onwards attentively [the] Dhamma [is] to be heard, thus.  
**Faithful:** After this you should attentively listen to the Dhamma.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`ito`** | `(ind)` [with *paraṁ*: from now on] from here, from this; **[ima + to]** |
| **`paraṁ`** | `(ind)` after, beyond, onwards; **[para + aṁ]** |
| **`sakkaccaṁ`** | `(ind)` attentively, respectfully, carefully; **[sat + kacca + aṁ]** |
| **`dhammo`** | `(masc nom sg)` Dhamma, teaching; **[√dhar + ma]** |
| **`sotabbo'ti`** | `(sandhi)` [*sotabbo* (ptp masc nom sg) should be heard + *iti* (ind), closing the quotation] should be listened to; **[√su > so + tabba; iti]** |
