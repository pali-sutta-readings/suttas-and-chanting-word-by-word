# Paṁsukūla-cīvara

*Taking Rag-cloth*

**Imaṁ paṁsukūla-cīvaraṁ assāmikaṁ mayhaṁ pāpuṇāti.**

**Literal:** This rag-robe-cloth, ownerless, to me reaches.  
**Faithful:** This rag-cloth, which is ownerless, has reached me.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`imaṁ`** | `(dem pron nt nom sg)` [agrees with *cīvaraṁ*] this; **[ima]** |
| **`paṁsukūla-cīvaraṁ`** | `(nt nom sg comp)` rag-cloth, robe-cloth from a rubbish heap; **[paṁsukūla + cīvara]** |
| ↳ **`paṁsukūla`** | `(nt comp)` rubbish-heap cloth, discarded rags; **[paṁsu + kūla]** |
| ↳ **`cīvaraṁ`** | `(nt nom sg)` robe-cloth, robe; **[cīvara, no root in DPD]** |
| **`assāmikaṁ`** | `(adj nt nom sg)` [agrees with *cīvaraṁ*] without an owner, ownerless; **[na > a + sāmī + ka]** |
| **`mayhaṁ`** | `(1st sg dat)` to me; **[ahaṁ]** |
| **`pāpuṇāti`** | `(3rd sg pres act indic)` reaches, comes to; **[pa + √ap + uṇā + ti]** |
