# Requesting a Dhamma Talk

> After bowing three times, with hands joined in añjali, recite the following:

**Brahmā ca lokādhipatī sahampati**

**Literal:** Brahmā and, lord of [the] world, Sahampati,  
**Faithful:** The Brahmā god Sahampati, Lord of the world,  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`brahmā`** | `(masc nom sg)` Brahmā, a god of the Brahmā world; **[√brah + ma]** |
| **`ca`** | `(ind)` and; **[ca]** |
| **`lokādhipatī`** | `(masc nom sg comp)` [final *-i* lengthened for the metre] lord of the world; **[loka + adhipati]** |
| ↳ **`lok'`** | `(masc comp)` [*loka* before a vowel] world; **[√lok + a]** |
| ↳ **`adhipatī`** | `(masc nom sg)` lord, ruler; **[adhi + √pat + i]** |
| **`sahampati`** | `(masc nom sg comp)` Sahampati, name of the Brahmā who implored the Buddha to teach; **[saha + pati]** |
| ↳ **`saham`** | `(ind comp)` [*saha* with *ṁ* in the name] with, together with; **[saha]** |
| ↳ **`pati`** | `(masc nom sg)` lord, master; **[√pat + i]** |

**Katañjalī anadhivaraṁ ayācatha**

**Literal:** With joined palms [the] Unsurpassed One [he] implored:  
**Faithful:** With palms joined in reverence, implored the Unsurpassed One:  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`katañjalī`** | `(adj masc nom sg comp)` with palms joined in reverence; **[kata + añjali]** |
| ↳ **`kat'`** | `(pp comp)` [*kata* before a vowel] made, done; **[√kar + ta]** |
| ↳ **`añjalī`** | `(adj masc nom sg)` [final *-i* lengthened] palms placed together (in reverence); **[√añj + ali]** |
| **`anadhivaraṁ`** | `(masc acc sg)` [DPD: epithet of the Buddha, lit. "with no one above"; BM's "a favour" is not supported] the Unsurpassed One, the Buddha; **[na > an + adhi + √var + a]** |
| **`ayācatha`** | `(3rd sg aor mid indic)` implored, begged, asked; **[a + √yāc + a + tha]** |

**Santīdha sattāpparajakkha-jātikā**

**Literal:** There are here beings of [a] nature with little dust in [their] eyes;  
**Faithful:** Beings are here with but little dust in their eyes,  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`santīdha`** | `(sandhi)` [*santi* (3rd pl pres act indic) there are + *idha* (ind) here] there are here; **[santi + idha]** |
| **`sattāpparajakkha-jātikā`** | `(sandhi)` [*sattā* (masc nom pl) beings + *apparajakkha-jātikā* (adj masc nom pl comp) of a nature with little dust in the eyes: *appa* little + *rajakkha* dust in the eye (*rajas* + *akkha*) + *jātika* of the nature of] beings with but little dust in their eyes; **[sa + tta; appa + rajas + akkha + jātika]** |

**Desetu dhammaṁ anukampimaṁ pajaṁ.**

**Literal:** May [he] teach [the] Dhamma; have compassion [for] this generation.  
**Faithful:** Pray, teach the Dhamma out of compassion for them.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`desetu`** | `(3rd sg pres caus act imperat)` [3rd person as polite address] may he teach, please teach; **[√dis > dese + tu]** |
| **`dhammaṁ`** | `(masc acc sg)` Dhamma, teaching; **[√dhar + ma]** |
| **`anukampimaṁ`** | `(sandhi)` [*anukampa* (2nd sg pres act imperat) have compassion (for) + *imaṁ* (dem pron fem acc sg) this, with *pajaṁ*; DPD also allows *anukampi* (aor)] have compassion for this; **[anu + √kamp + a; ima]** |
| **`pajaṁ`** | `(fem acc sg)` generation, people, beings; **[pa + √jan + ā]** |

*(Bow three times)*
