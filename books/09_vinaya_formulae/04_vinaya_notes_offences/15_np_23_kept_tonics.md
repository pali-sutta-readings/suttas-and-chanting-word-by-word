# Nissaggiya Pācittiya 23

*Kept Tonics*

**Idaṁ me bhante bhesajjaṁ sattāhātikkantaṁ nissaggiyaṁ. Imāhaṁ āyasmato nissajjāmi.**

**Literal:** This by me, venerable sir, tonic, beyond seven days, [is] to be forfeited. This I to [the] venerable [one] forfeit.  
**Faithful:** This tonic, ven. sir, which has passed beyond the seven-day (limit), is to be forfeited by me: I forfeit it to you.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`idaṁ`** | `(dem pron nt nom sg)` this; **[ima]** |
| **`me`** | `(1st sg instr)` [enclitic; agent of *nissaggiyaṁ*] by me; **[ahaṁ]** |
| **`bhante`** | `(masc voc sg)` venerable sir; **[√bhū > bhava + nta + e]** |
| **`bhesajjaṁ`** | `(nt nom sg)` tonic, medicine; **[bhisaja > bhesaja + ya]** |
| **`sattāhātikkantaṁ`** | `(adj nt nom sg comp)` kept more than seven days, past the seven-day (limit); **[sattāha + atikkanta]** |
| ↳ **`sattāha`** | `(nt comp)` seven days, a week; **[satta + aha]** |
| ↳ **`atikkantaṁ`** | `(pp nt nom sg)` gone beyond, exceeded; **[ati + √kam + ta]** |
| **`nissaggiyaṁ`** | `(ptp nt nom sg)` to be forfeited, to be given up; **[nī + √sajj > sagg + iya]** |
| **`imāhaṁ`** | `(sandhi)` [*imaṁ* (dem pron nt acc sg) this + *ahaṁ* (1st sg nom) I] this I; **[ima; ahaṁ]** |
| **`āyasmato`** | `(masc dat sg)` to the venerable one, to you; **[ā + √i > ay + as + mant]** |
| **`nissajjāmi`** | `(1st sg pres act indic)` I forfeit, I give up, I hand over; **[nī + √sajj + a + mi]** |

> Tonics can be returned, but not for consumption:

**Imaṁ bhesajjaṁ āyasmato dammi.**

**Literal:** This tonic to [the] venerable [one] [I] give.  
**Faithful:** I give this tonic to you.
