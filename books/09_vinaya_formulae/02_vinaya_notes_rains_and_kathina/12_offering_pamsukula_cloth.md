# Offering Paṁsukūla-cloth

> If the community during the Vassa has been less than five bhikkhus, the lay supporters may offer Paṁsukūla-cloth instead of a *Kaṭhina*:

**Mayaṁ bhante, imasmiṁ kaṭhinasamaye,**

**Literal:** We, venerable sirs, in this Kaṭhina-season,  
**Faithful:** May we, Venerable Sirs, in this Kaṭhina season, offer these Paṁsukūla-cloths to the Saṅgha, together with other requisites.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`mayaṁ`** | `(1st pl nom)` we; **[ahaṁ]** |
| **`bhante`** | `(masc voc pl)` venerable sirs; **[√bhū > bhava + nta + e]** |
| **`imasmiṁ`** | `(dem pron masc loc sg)` [agrees with *kaṭhinasamaye*] in this; **[ima]** |
| **`kaṭhinasamaye`** | `(masc loc sg comp)` in the Kaṭhina season, at the time of the Kaṭhina; **[kaṭhina + samaya]** |
| ↳ **`kaṭhina`** | `(nt comp)` Kaṭhina (the robe-making privileges after the Rains); **[kaṭhina, no root in DPD]** |
| ↳ **`samaye`** | `(masc loc sg)` at the time, in the season; **[saṁ + √i > ay + a]** |

**imāni paṁsukūlacīvarāni saparivārāni saṅghassa oṇojayāma.**

**Literal:** these rag-robe cloths with [their] accompaniments to [the] Community we dedicate.  
**Faithful:** (continued)  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`imāni`** | `(dem pron nt acc pl)` these; **[ima]** |
| **`paṁsukūlacīvarāni`** | `(nt acc pl comp)` Paṁsukūla-cloths, rag-robe cloths; **[paṁsukūla + cīvara]** |
| ↳ **`paṁsukūla`** | `(nt comp)` discarded cloth, rags (from a rubbish heap); **[paṁsu + kūla]** |
| ↳ **`cīvarāni`** | `(nt acc pl)` robes, robe-cloths; **[cīvara, no root in DPD]** |
| **`saparivārāni`** | `(adj nt acc pl)` [agrees with *paṁsukūlacīvarāni*] together with accompanying requisites; lit. with a retinue; **[sa + pari + √var + e + a]** |
| **`saṅghassa`** | `(masc dat sg)` to the Community, to the Saṅgha; **[saṁ + √ghaṭ + a]** |
| **`oṇojayāma`** | `(1st pl pres caus act indic)` we dedicate, we present, we offer; **[ava + √nud > ṇoj + aya + ma]** |

**Sādhu no bhante saṅgho,**

**Literal:** Good [it would be] for us, venerable sirs, [if the] Community,  
**Faithful:** Please accept these Paṁsukūla-cloths and other requisites,  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`sādhu`** | `(ind)` it would be good, please; **[√sādh + u]** |
| **`no`** | `(1st pl dat)` for us; **[ahaṁ]** |
| **`bhante`** | `(masc voc pl)` venerable sirs; **[√bhū > bhava + nta + e]** |
| **`saṅgho`** | `(masc nom sg)` Community, Saṅgha; **[saṁ + √ghaṭ + a]** |

**imāni paṁsukūlacīvarāni saparivārāni paṭiggaṇhātu,**

**Literal:** these rag-robe cloths with [their] accompaniments may accept,  
**Faithful:** (continued)  

| Word | Analysis & Meaning |

| **`imāni`** | `(dem pron nt acc pl)` these; **[ima]** |
| **`paṁsukūlacīvarāni`** | `(nt acc pl comp)` Paṁsukūla-cloths, rag-robe cloths; **[paṁsukūla + cīvara]** |
| ↳ **`paṁsukūla`** | `(nt comp)` discarded cloth, rags (from a rubbish heap); **[paṁsu + kūla]** |
| ↳ **`cīvarāni`** | `(nt acc pl)` robes, robe-cloths; **[cīvara, no root in DPD]** |
| **`saparivārāni`** | `(adj nt acc pl)` [agrees with *paṁsukūlacīvarāni*] together with accompanying requisites; lit. with a retinue; **[sa + pari + √var + e + a]** |
| **`paṭiggaṇhātu`** | `(3rd sg pres act imperat)` may (it) accept, may (it) receive; **[pati + √gah + ṇhā + tu]** |

**Amhākaṁ dīgharattaṁ hitāya sukhāya**

**Literal:** For us for a long time for welfare, for happiness  
**Faithful:** for our long-lasting welfare and happiness.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`amhākaṁ`** | `(1st pl dat/gen)` for us, our; **[ahaṁ]** |
| **`dīgharattaṁ`** | `(adv comp)` for a long time; **[dīgha + ratta + aṁ]** |
| ↳ **`dīgha`** | `(adj comp)` long; **[dīgha, no root in DPD]** |
| ↳ **`rattaṁ`** | `(nt acc sg)` time, nights; **[ratti + a]** |
| **`hitāya`** | `(nt dat sg)` for the welfare, for the benefit; **[√dhā > (da)h + ita]** |
| **`sukhāya`** | `(nt dat sg)` for the happiness, for the ease; **[√sukh + a]** |
