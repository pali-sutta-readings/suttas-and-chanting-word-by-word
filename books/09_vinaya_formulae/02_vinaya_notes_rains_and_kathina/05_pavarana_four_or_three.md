# Pavāraṇā

*Inviting Admonition: Four or Three Bhikkhus*

> Preliminary duties, then the *ñatti*:

**Suṇantu me āyasmanto,**

**Literal:** May listen [to] me [the] venerable ones,  
**Faithful:** Sirs, may you listen to me.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`suṇantu`** | `(3rd pl pres act imperat)` may (they) listen, let (them) hear; **[√su + ṇā + ntu]** |
| **`me`** | `(1st sg gen)` [genitive with a verb of hearing] to me, me; **[ahaṁ]** |
| **`āyasmanto`** | `(masc nom pl)` [polite address] the venerable ones, you, sirs; **[ā + √i > ay + as + mant]** |

**ajja pavāraṇā paṇṇarasī,**

**Literal:** today [is the] invitation [on the] fifteenth,  
**Faithful:** Today is the pavāraṇā on the 15th (day of the fortnight).  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`ajja`** | `(ind)` today; **[ima + jja]** |
| **`pavāraṇā`** | `(fem nom sg)` invitation (to admonition), Pavāraṇā; **[pa + √var + e + anā]** |
| **`paṇṇarasī`** | `(fem nom sg)` [agrees with *pavāraṇā*] (on the) fifteenth (day of the fortnight); **[pañca + dasa + ī]** |

**yad'āyasmantānaṁ pattakallaṁ, mayaṁ aññamaññaṁ pavāreyyāma.**

**Literal:** if for [the] venerable ones [it is the] right time, we one another should invite.  
**Faithful:** If there is complete preparedness of the ven. ones, we should invite one another.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`yad'āyasmantānaṁ`** | `(sandhi)` [*yadi* (ind) if + *āyasmantānaṁ* (masc dat pl) for the venerable ones] if for the venerable ones; **[yadi; ā + √i > ay + as + mant]** |
| **`pattakallaṁ`** | `(nt nom sg comp)` the right time, a suitable occasion; readiness; **[patta + kalla]** |
| ↳ **`patta`** | `(pp comp)` reached, arrived (at); **[pa + √ap + ta]** |
| ↳ **`kallaṁ`** | `(nt nom sg)` good time, suitable occasion; **[√kal + ya]** |
| **`mayaṁ`** | `(1st pl nom)` we; **[ahaṁ]** |
| **`aññamaññaṁ`** | `(pron masc acc sg)` one another, each other; **[aññaṁ + aññaṁ]** |
| **`pavāreyyāma`** | `(1st pl act opt)` we should invite, let us make the Pavāraṇā; **[pa + √var + e + eyyāma]** |

**Variant:** if there are three bhikkhus: *āyasmanto* → *āyasmantā*  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`āyasmantā`** | `(masc nom pl)` [polite address] the venerable ones, you, sirs; **[ā + √i > ay + as + mant]** |

> Then each bhikkhu in order of Rains:

**Ahaṁ bhante āyasmante pavāremi.**

**Literal:** I, venerable sirs, [the] venerable ones invite.  
**Faithful:** Ven. sirs, I invite admonition from the ven. ones.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`ahaṁ`** | `(1st sg nom)` I; **[ahaṁ]** |
| **`bhante`** | `(masc voc pl)` venerable sirs; **[√bhū > bhava + nta + e]** |
| **`āyasmante`** | `(masc acc pl)` the venerable ones; **[ā + √i > ay + as + mant]** |
| **`pavāremi`** | `(1st sg pres act indic)` I invite (admonition from), I make the Pavāraṇā (to); **[pa + √var + e + mi]** |

**Diṭṭhena vā sutena vā parisaṅkāya vā, vadantu maṁ āyasmanto anukampaṁ upādāya.**

**Literal:** By [what is] seen or by [what is] heard or by suspicion or, may speak [to] me [the] venerable ones, compassion taking up.  
**Faithful:** According to what has been seen, heard or suspected, may the ven. ones instruct me out of compassion.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`diṭṭhena`** | `(pp nt instr sg)` by what has been seen; **[√dis + ta]** |
| **`vā`** | `(ind)` or; **[vā]** |
| **`sutena`** | `(pp nt instr sg)` by what has been heard; **[√su + ta]** |
| **`vā`** | `(ind)` or; **[vā]** |
| **`parisaṅkāya`** | `(fem instr sg)` by suspicion; **[pari + √saṅk + ā]** |
| **`vā`** | `(ind)` or; **[vā]** |
| **`vadantu`** | `(3rd pl pres act imperat)` may (they) speak (to), may (they) tell, may (they) instruct; **[√vad + a + ntu]** |
| **`maṁ`** | `(1st sg acc)` me; **[ahaṁ]** |
| **`āyasmanto`** | `(masc nom pl)` the venerable ones; **[ā + √i > ay + as + mant]** |
| **`anukampaṁ`** | `(fem acc sg)` compassion, concern; **[anu + √kamp + ā]** |
| **`upādāya`** | `(abs)` out of, on account of; lit. taking up; **[upa + √ādā + ya]** |
