# Pavāraṇā

*Inviting Admonition: One Bhikkhu*

> Preliminary duties, then:

**Ajja me pavāraṇā.**

**Literal:** Today my invitation [is].  
**Faithful:** Today is my pavāraṇā.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`ajja`** | `(ind)` today; **[ima + jja]** |
| **`me`** | `(1st sg gen)` my; **[ahaṁ]** |
| **`pavāraṇā`** | `(fem nom sg)` invitation (to admonition), Pavāraṇā; **[pa + √var + e + anā]** |

*Kd 4:5.8*
