# Yan-dāni me kataṁ puññaṁ

*Aspiration through the Merit Made*

**Yan-dāni me kataṁ puññaṁ**

**Literal:** Whatever now by-me done merit,  
**Faithful:** Whatever merit I have now made,  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`yan-dāni`** | `(sandhi)` [*yaṁ* (rel pron nt nom sg) + *idāni* (ind)] whatever, now; **[ya + idāni (ima + dāni)]** |
| **`me`** | `(1st sg instr)` by me; **[ahaṁ]** |
| **`kataṁ`** | `(pp nt nom sg)` done, made; **[√kar + ta]** |
| **`puññaṁ`** | `(nt nom sg)` merit, good deed; **[√puṇ + ya]** |
