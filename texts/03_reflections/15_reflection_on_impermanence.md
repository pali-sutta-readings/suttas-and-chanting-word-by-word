**Handa mayaṁ aniccānussati-pāṭhaṁ bhaṇāmase**

**Literal:** Come now, we [the] impermanence-recollection-passage let us recite  
**Faithful:** Come now, let us recite the passage for recollecting impermanence.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`handa`** | `(interj)` come now, well then; **[handa]** |
| **`mayaṁ`** | `(1st pl nom)` we; **[ahaṁ]** |
| **`aniccānussati-pāṭhaṁ`** | `(masc acc sg comp)` passage for recollecting impermanence; **[anicca + anussati + pāṭha]** |
| ↳ **`anicca`** | `(adj comp)` impermanent; impermanence; **[na > a + ni + tya]** |
| ↳ **`anussati`** | `(fem comp)` recollection; **[anu + √sar + ti]** |
| ↳ **`pāṭhaṁ`** | `(masc acc sg)` passage, text for recitation; **[√paṭh > pāṭh + a]** |
| **`bhaṇāmase`** | `(1st pl pres mid imperat)` let us recite, let us say; **[√bhaṇ + a + mase]** |
