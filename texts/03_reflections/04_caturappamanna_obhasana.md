# Caturappamaññā-obhāsana

*Radiating the Four Immeasurables*

**Handa mayaṁ caturappamaññā-obhāsanaṁ karomase**

**Literal:** Come now, we [the] four-immeasurables-radiating let us do  
**Faithful:** Now let us radiate the four immeasurables.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`handa`** | `(interj)` come now, well then; **[handa]** |
| **`mayaṁ`** | `(1st pl nom)` we; **[ahaṁ]** |
| **`caturappamaññā-obhāsanaṁ`** | `(nt acc sg comp)` radiating of the four immeasurables; **[catu + appamaññā + obhāsana]** |
| ↳ **`catur`** | `(card comp)` four; **[catu]** |
| ↳ **`appamaññā`** | `(fem comp)` immeasurable [state of mind]; **[na > a + pa + √mā + aṇa + yā]** |
| ↳ **`obhāsanaṁ`** | `(nt acc sg)` illuminating, radiating; **[ava + √bhās + ana]** |
| **`karomase`** | `(1st pl pres mid imperat)` let us do, let us make; **[√kar + o + mase]** |

**Tathā dutiyaṁ tathā tatiyaṁ tathā catutthaṁ**

| **`tathā`** | `(ind)` likewise, in the same way; **[ta + thā]** |

**Iti uddhamadho tiriyaṁ sabbadhi sabbattatāya**

**Literal:** Thus above [and] below, across, everywhere, to all as to oneself  
**Faithful:** so above, below, across and everywhere, to all as to oneself,  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`iti`** | `(ind)` thus, so; **[iti]** |
| **`uddhamadho`** | `(ind comp)` above and below; **[uddhaṁ + adho]** |
| ↳ **`uddham`** | `(ind comp)` above, upwards; **[ud + dha + aṁ]** |
| ↳ **`adho`** | `(ind)` below, downwards; **[adho]** |
| **`tiriyaṁ`** | `(ind)` across, horizontally; **[√tir + iya + aṁ]** |
| **`sabbadhi`** | `(ind)` everywhere, in every way; **[sabba + dhi]** |
| **`sabbattatāya`** | `(adv comp)` to all as to oneself, encompassing all beings; **[sabba + attatā + āya]** |
| ↳ **`sabba`** | `(pron comp)` all; **[sabba]** |
| ↳ **`attatāya`** | `(fem dat sg)` being oneself, identification [with others]; **[atta + tā]** |
