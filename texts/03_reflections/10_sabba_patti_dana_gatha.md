# Sabba-patti-dāna-gāthā

*Verses on Sharing Merit with All Beings*

**Handa mayaṁ sabba-patti-dāna-gāthāyo bhaṇāmase**

**Literal:** Come now, we [the] all-merit-sharing-verses let us recite  
**Faithful:** Now let us recite the verses for sharing merit with all beings.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`handa`** | `(interj)` come now, well then; **[handa]** |
| **`mayaṁ`** | `(1st pl nom)` we; **[ahaṁ]** |
| **`sabba-patti-dāna-gāthāyo`** | `(fem acc pl comp)` verses for sharing merit with all; **[sabba + patti + dāna + gāthā]** |
| ↳ **`sabba`** | `(pron comp)` all; **[sabba]** |
| ↳ **`patti`** | `(fem comp)` share [of merit]; **[pa + √ap + ti]** |
| ↳ **`dāna`** | `(nt comp)` giving; **[√dā + ana]** |
| ↳ **`gāthāyo`** | `(fem acc pl)` verses; **[√gā + thā]** |
| **`bhaṇāmase`** | `(1st pl pres mid imperat)` let us recite, let us say; **[√bhaṇ + a + mase]** |
