# Dhaj'agga-sutta

*The Discourse on the Top of the Banner*

**Evam-me sutaṁ.**

**Literal:** Thus by me heard.  
**Faithful:** Thus have I heard.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`evam-me`** | `(sandhi)` [*evaṁ* (ind) + *me* (1st sg instr)] thus by me; **[eva + aṁ; ahaṁ]** |
| **`sutaṁ`** | `(pp nt nom sg)` heard; **[√su + ta]** |

**Ekaṁ samayaṁ Bhagavā, Sāvatthiyaṁ viharati, Jeta-vane Anāthapiṇḍikassa ārāme.**

**Literal:** One time the Blessed One at Sāvatthī dwells, in Jeta's Grove, in Anāthapiṇḍika's park.  
**Faithful:** On one occasion the Blessed One was staying near Sāvatthī, in Jeta's Grove, Anāthapiṇḍika's monastery.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`ekaṁ`** | `(card masc acc sg)` one; **[eka]** |
| **`samayaṁ`** | `(masc acc sg)` [accusative of time] time, occasion; **[saṁ + √i > ay + a]** |
| **`bhagavā`** | `(masc nom sg)` the Blessed One; **[√bhaj > bhag + a + vant]** |
| **`sāvatthiyaṁ`** | `(fem loc sg)` at Sāvatthī, near Sāvatthī; **[√su > sāv + a + ttha + ī]** |
| **`viharati`** | `(3rd sg pres act indic)` [historic present] dwells, was staying; **[vi + √har + a + ti]** |
| **`jeta-vane`** | `(nt loc sg comp)` in Jeta's Grove; **[jeta + vana]** |
| ↳ **`jeta`** | `(masc comp)` Jeta, a prince of Sāvatthī; **[√ji > je + ta]** |
| ↳ **`vane`** | `(nt loc sg)` grove, wood; **[vana, no root in DPD]** |
| **`anāthapiṇḍikassa`** | `(masc gen sg comp)` of Anāthapiṇḍika, "feeder of the helpless"; **[anātha + piṇḍika]** |
| ↳ **`anātha`** | `(adj comp)` helpless, without protector; **[na > a + √nāth + a]** |
| ↳ **`piṇḍikassa`** | `(masc gen sg)` giver of alms food; **[piṇḍa + ika; *piṇḍika* not a headword in DPD]** |
| **`ārāme`** | `(masc loc sg)` in the monastery, in the park; **[ā + √ram > rām + a]** |

**Bhūta-pubbaṁ bhikkhave devāsura-saṅgāmo samupabbūḷho ahosi.**

**Literal:** Formerly, bhikkhus, a deva-asura battle arrayed was.  
**Faithful:** Once, bhikkhus, a battle between the devas and the asuras had been drawn up.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`bhūta-pubbaṁ`** | `(adv comp)` [adverbial accusative of *bhūtapubba*] formerly, once upon a time; **[bhūta + pubba]** |
| ↳ **`bhūta`** | `(pp comp)` happened, been; **[√bhū + ta]** |
| ↳ **`pubbaṁ`** | `(adv)` before, previously; **[pubba, no root in DPD]** |
| **`bhikkhave`** | `(masc voc pl)` bhikkhus, monks; **[√bhikkh + u + ave]** |
| **`devāsura-saṅgāmo`** | `(masc nom sg comp)` battle between the devas and the asuras; **[deva + asura + saṅgāma]** |
| ↳ **`deva`** | `(masc comp)` deva, god; **[√div > dev + a]** |
| ↳ **`asura`** | `(masc comp)` asura, titan; **[na > a + √sur + a]** |
| ↳ **`saṅgāmo`** | `(masc nom sg)` battle; **[saṁ + √gam > gāme + a]** |
| **`samupabbūḷho`** | `(pp masc nom sg)` [BM's spelling; DPD also has *samupabyūḷha*] arrayed for battle, drawn up; **[saṁ + upa + vi + √yūh + ta > yūḍha > yūḷha]** |
| **`ahosi`** | `(3rd sg aor act indic)` was, had been; **[a + √hū > ho + si]** |
