# Vibhaṅga

*The Analysis*

**Pañcakkhandhā rūpakkhandho, vedanākkhandho, saññākkhandho, saṅkhārakkhandho, viññāṇakkhandho.**

**Literal:** Five-aggregates: form-aggregate, feeling-aggregate, perception-aggregate, formations-aggregate, consciousness-aggregate.  
**Faithful:** The five aggregates: the aggregate of form, the aggregate of feeling, the aggregate of perception, the aggregate of formations, the aggregate of consciousness.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`pañcakkhandhā`** | `(masc nom pl comp)` the five aggregates; **[pañca + khandha]** |
| ↳ **`pañca`** | `(card comp)` five; **[pañca]** |
| ↳ **`khandhā`** | `(masc nom pl)` aggregates, masses, groups; **[√khandh + a]** |
| **`rūpakkhandho`** | `(masc nom sg comp)` the aggregate of form; **[rūpa + khandha]** |
| ↳ **`rūpa`** | `(nt comp)` form, materiality; **[√rūp + a]** |
| ↳ **`khandho`** | `(masc nom sg)` aggregate, mass; **[√khandh + a]** |
| **`vedanākkhandho`** | `(masc nom sg comp)` the aggregate of feeling; **[vedanā + khandha]** |
| ↳ **`vedanā`** | `(fem comp)` feeling, felt experience; **[√vid > ved + anā]** |
| ↳ **`khandho`** | `(masc nom sg)` aggregate, mass; **[√khandh + a]** |
| **`saññākkhandho`** | `(masc nom sg comp)` the aggregate of perception; **[saññā + khandha]** |
| ↳ **`saññā`** | `(fem comp)` perception, recognition; **[saṁ + √ñā + ā]** |
| ↳ **`khandho`** | `(masc nom sg)` aggregate, mass; **[√khandh + a]** |
| **`saṅkhārakkhandho`** | `(masc nom sg comp)` the aggregate of (volitional) formations; **[saṅkhāra + khandha]** |
| ↳ **`saṅkhāra`** | `(masc comp)` volitional formation, mental formation; **[saṁ + √kar > khār + a]** |
| ↳ **`khandho`** | `(masc nom sg)` aggregate, mass; **[√khandh + a]** |
| **`viññāṇakkhandho`** | `(masc nom sg comp)` the aggregate of consciousness; **[viññāṇa + khandha]** |
| ↳ **`viññāṇa`** | `(nt comp)` consciousness; **[vi + √ñā + aṇa]** |
| ↳ **`khandho`** | `(masc nom sg)` aggregate, mass; **[√khandh + a]** |

**Tattha katamo rūpakkhandho.**

**Literal:** There which [is the] form-aggregate?  
**Faithful:** Among these, what is the aggregate of form?  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`tattha`** | `(ind)` there, in that regard, among these; **[ta + ttha]** |
| **`katamo`** | `(interr pron masc nom sg)` which?, what?; **[ka + tama]** |
| **`rūpakkhandho`** | `(masc nom sg comp)` the aggregate of form; **[rūpa + khandha]** |
| ↳ **`rūpa`** | `(nt comp)` form, materiality; **[√rūp + a]** |
| ↳ **`khandho`** | `(masc nom sg)` aggregate, mass; **[√khandh + a]** |

**Yaṁ kiñci rūpaṁ atītānāgata-paccuppannaṁ**

**Literal:** Whatever any form past-future-present,  
**Faithful:** Whatever form there is, whether past, future or present,  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`yaṁ`** | `(rel pron nt nom sg)` which, whatever; **[ya]** |
| **`kiñci`** | `(ind)` any, whatever; **[ka > ki + iṁ + ci]** |
| **`rūpaṁ`** | `(nt nom sg)` form, material form; **[√rūp + a]** |
| **`atītānāgata-paccuppannaṁ`** | `(pp nt nom sg comp)` past, future or present; **[atīta + anāgata + paccuppanna]** |
| ↳ **`atīta`** | `(pp comp)` past; **[ati + √i + ta]** |
| ↳ **`anāgata`** | `(pp comp)` future, not yet come; **[na > an + ā + √gam + ta]** |
| ↳ **`paccuppannaṁ`** | `(pp nt nom sg)` present, presently arisen; **[pati > pacc + ud + √pad + na]** |
