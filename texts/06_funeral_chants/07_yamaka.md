# Yamaka

*The Pairs*

**Ye keci kusalā dhammā, sabbe te kusalamūlā.**

**Literal:** Whichever any wholesome phenomena, all those wholesome-roots?  
**Faithful:** Whatever phenomena are wholesome, are they all wholesome roots?  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`ye`** | `(rel pron masc nom pl)` which, whatever; **[ya]** |
| **`keci`** | `(pron masc nom pl)` any, whatever; **[ka + e + ci]** |
| **`kusalā`** | `(adj masc nom pl)` wholesome, skilful, beneficial; **[kusala, no root in DPD]** |
| **`dhammā`** | `(masc nom pl)` phenomena, things; **[√dhar + ma]** |
| **`sabbe`** | `(pron masc nom pl)` all; **[sabba]** |
| **`te`** | `(dem pron masc nom pl)` those, they; **[ta]** |
| **`kusalamūlā`** | `(nt nom pl comp)` [the Yamaka puts each statement as a question] wholesome roots; **[kusala + mūla]** |
| ↳ **`kusala`** | `(adj comp)` wholesome; **[kusala, no root in DPD]** |
| ↳ **`mūlā`** | `(nt nom pl)` roots; **[√mūl + a]** |
