# Kathāvatthu

*The Points of Controversy*

**Puggalo upalabbhati saccikaṭṭha-paramatthenā'ti.**

**Literal:** [Is a] person found by-real-meaning-[and]-ultimate-meaning?  
**Faithful:** "Is a person found as a real and ultimate fact?"  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`puggalo`** | `(masc nom sg)` person, individual; **[puggala, no root in DPD]** |
| **`upalabbhati`** | `(3rd sg pres pass indic)` is found, is obtained, exists; **[upa + √labh + ya + ti]** |
| **`saccikaṭṭha-paramatthenā'ti`** | `(masc instr sg comp)` [*-ena* + *iti* (ind), closing the question] as (a) real and ultimate meaning, as a real and ultimate fact; **[saccikaṭṭha + paramattha; + iti]** |
| ↳ **`saccikaṭṭha`** | `(masc comp)` real meaning, true fact; **[saccika + aṭṭha]** |
| ↳ **`paramatthenā`** | `(masc instr sg)` [final *-a* lengthened before *iti*] by the ultimate meaning, as an ultimate fact; **[parama + attha]** |

**Āmantā.**

**Faithful:** "Yes."  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`āmantā`** | `(ind)` yes, (it is) so (affirming); **[āmantā]** |

**Yo saccikaṭṭho paramattho, tato so puggalo upalabbhati saccikaṭṭha-paramatthenā'ti.**

**Literal:** Which real-meaning ultimate-meaning, from-that that person is found by-real-meaning-[and]-ultimate-meaning?  
**Faithful:** "Is the person found as a real and ultimate fact in the way that a real and ultimate fact [is found]?"

**Na h'evaṁ vattabbe.**

**Literal:** Not indeed thus to-be-said.  
**Faithful:** "That should not indeed be said."  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`na`** | `(ind)` not; **[na]** |
| **`h'evaṁ`** | `(sandhi)` [*hi* (ind) + *evaṁ* (ind)] indeed thus; **[hi + evaṁ]** |
| **`vattabbe`** | `(ptp nt nom sg)` [eastern nominative in *-e*] to be said, should be said; **[√vad + tabba]** |

**Ājānāhi niggahaṁ.**

**Literal:** Acknowledge [the] refutation.  
**Faithful:** "Acknowledge the refutation:  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`ājānāhi`** | `(2nd sg pres act imperat)` acknowledge, understand, know; **[ā + √ñā > jānā + hi]** |
| **`niggahaṁ`** | `(masc acc sg)` refutation, rebuke; **[ni + √gah + a]** |

**Hañci puggalo upalabbhati saccikaṭṭha-paramatthena, tena vata re vattabbe.**

**Literal:** If person is found by-real-meaning-[and]-ultimate-meaning, then surely, hey, [it is] to-be-said:  
**Faithful:** if a person is found as a real and ultimate fact, then surely, my friend, it should be said:  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`hañci`** | `(ind)` if; **[hañci]** |
| **`puggalo`** | `(masc nom sg)` person, individual; **[puggala, no root in DPD]** |
| **`upalabbhati`** | `(3rd sg pres pass indic)` is found, is obtained, exists; **[upa + √labh + ya + ti]** |
| **`saccikaṭṭha-paramatthena`** | `(masc instr sg comp)` as (a) real and ultimate meaning, as a real and ultimate fact; **[saccikaṭṭha + paramattha]** |
| ↳ **`saccikaṭṭha`** | `(masc comp)` real meaning, true fact; **[saccika + aṭṭha]** |
| ↳ **`paramatthena`** | `(masc instr sg)` by the ultimate meaning, as an ultimate fact; **[parama + attha]** |
| **`tena`** | `(dem pron nt instr sg)` [used as an adverb] then, therefore; **[ta]** |
| **`vata`** | `(ind)` surely, certainly; **[vata]** |
| **`re`** | `(ind)` [a sharp form of address in debate] hey!, you there!; **[are > re]** |
| **`vattabbe`** | `(ptp nt nom sg)` [eastern nominative in *-e*] to be said, should be said; **[√vad + tabba]** |
