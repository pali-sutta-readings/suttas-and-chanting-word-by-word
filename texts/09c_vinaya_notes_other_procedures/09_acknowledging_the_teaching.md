# Acknowledging the Teaching

> After the talk, the person next in seniority after the speaker chants:

**Handa mayaṁ dhamma-kathāya sādhukāraṁ dadāmase.**

**Literal:** Come now, we to [the] Dhamma-talk approval let us give.  
**Faithful:** Now let us express our approval of this Dhamma teaching.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`handa`** | `(interj)` come now, well then; **[handa]** |
| **`mayaṁ`** | `(1st pl nom)` we; **[ahaṁ]** |
| **`dhamma-kathāya`** | `(fem dat sg comp)` to the Dhamma talk, for the Dhamma teaching; **[dhamma + kathā]** |
| ↳ **`dhamma`** | `(masc comp)` Dhamma, teaching; **[√dhar + ma]** |
| ↳ **`kathāya`** | `(fem dat sg)` to the talk; **[√kath + ā]** |
| **`sādhukāraṁ`** | `(masc acc sg comp)` approval, applause, saying *sādhu*; **[sādhu + kāra]** |
| ↳ **`sādhu`** | `(ind comp)` good, well; **[√sādh + u]** |
| ↳ **`kāraṁ`** | `(masc acc sg)` making, act (of saying); **[√kar > kār + a]** |
| **`dadāmase`** | `(1st pl pres mid imperat)` let us give; **[√dā + dā + a + mase]** |

**Variant:** for an exhortation: *dhamma-kathāya* → *ovāda-kathāya*  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`ovāda-kathāya`** | `(fem dat sg comp)` to the exhortation, for the talk of advice; **[ovāda + kathā]** |
| ↳ **`ovāda`** | `(masc comp)` exhortation, advice, instruction; **[ava + √vad > vād + a]** |
| ↳ **`kathāya`** | `(fem dat sg)` to the talk; **[√kath + ā]** |

> The listeners, together:

**Sādhu, sādhu, sādhu. Anumodāmi.**

**Literal:** Good, good, good. I appreciate.  
**Faithful:** It is well, I appreciate it.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`sādhu`** | `(ind)` it is good, well; **[√sādh + u]** |
| **`sādhu`** | `(ind)` it is good, well; **[√sādh + u]** |
| **`sādhu`** | `(ind)` it is good, well; **[√sādh + u]** |
| **`anumodāmi`** | `(1st sg pres act indic)` I appreciate, I approve (of), I rejoice (in); **[anu + √mud > moda + mi]** |

> When the talk on Vinaya or Dhamma is concluded, the speaker chants:

**Ayaṁ dhamma-kathā sādh'āyasmantehi saṁrakkhetabbā'ti.**

**Literal:** This Dhamma-talk well by [the] venerable ones [is] to be preserved, thus.  
**Faithful:** This talk on Dhamma should be well-preserved by you, ven. sirs.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`ayaṁ`** | `(dem pron fem nom sg)` this; **[ima]** |
| **`dhamma-kathā`** | `(fem nom sg comp)` talk on Dhamma; **[dhamma + kathā]** |
| ↳ **`dhamma`** | `(masc comp)` Dhamma, teaching; **[√dhar + ma]** |
| ↳ **`kathā`** | `(fem nom sg)` talk, speech; **[√kath + ā]** |
| **`sādh'āyasmantehi`** | `(sandhi)` [*sādhu* (ind) well + *āyasmantehi* (masc instr pl) by the venerable ones, agent of *saṁrakkhetabbā*] well ... by the venerable ones; **[√sādh + u; ā + √i > ay + as + mant]** |
| **`saṁrakkhetabbā'ti`** | `(sandhi)` [*saṁrakkhetabbā* (ptp fem nom sg, agrees with *kathā*) should be preserved + *iti* (ind), closing the quotation; not in DPD, from *saṁrakkhati*] should be preserved, should be guarded; **[saṁ + √rakkh + etabba; iti]** |

**Variant:** for a talk on Vinaya: *dhamma-kathā* → *vinaya-kathā*  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`vinaya-kathā`** | `(fem nom sg comp)` talk on Vinaya; **[vinaya + kathā]** |
| ↳ **`vinaya`** | `(masc comp)` Vinaya, discipline, training; **[vi + √nī > nay + a]** |
| ↳ **`kathā`** | `(fem nom sg)` talk, speech; **[√kath + ā]** |

**Variant:** for a talk on Dhamma and Vinaya: *dhamma-kathā* → *dhammavinaya-kathā*  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`dhammavinaya-kathā`** | `(fem nom sg comp)` talk on the Dhamma and Vinaya; **[dhamma + vinaya + kathā]** |
| ↳ **`dhamma`** | `(masc comp)` Dhamma, teaching; **[√dhar + ma]** |
| ↳ **`vinaya`** | `(masc comp)` Vinaya, discipline, training; **[vi + √nī > nay + a]** |
| ↳ **`kathā`** | `(fem nom sg)` talk, speech; **[√kath + ā]** |
