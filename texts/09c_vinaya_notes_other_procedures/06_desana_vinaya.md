# Desanā

*Requesting Permission to Speak on Vinaya*

> After bowing three times, with hands joined in añjali, addressing the senior elder:

**Okāsaṁ me bhante thero detu vinaya-kathaṁ kathetuṁ.**

**Literal:** Opportunity to me, venerable sir, [the] elder may give, [a] Vinaya-talk to speak.  
**Faithful:** Ven. sir, please give permission to speak on Vinaya.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`okāsaṁ`** | `(masc acc sg)` opportunity, permission, leave; **[ava + √kās + a]** |
| **`me`** | `(1st sg dat)` to me, for me; **[ahaṁ]** |
| **`bhante`** | `(masc voc sg)` venerable sir; **[√bhū > bhava + nta + e]** |
| **`thero`** | `(masc nom sg)` [3rd person as polite address] the elder; **[√ṭhā > thā + ira > thera]** |
| **`detu`** | `(3rd sg pres act imperat)` may he give, please give; **[√dā > de + tu]** |
| **`vinaya-kathaṁ`** | `(fem acc sg comp)` talk on Vinaya; **[vinaya + kathā]** |
| ↳ **`vinaya`** | `(masc comp)` Vinaya, discipline, training; **[vi + √nī > nay + a]** |
| ↳ **`kathaṁ`** | `(fem acc sg)` talk, speech; **[√kath + ā]** |
| **`kathetuṁ`** | `(inf)` to speak, to give (a talk); **[√kath + e + tuṁ]** |

**Namo tassa bhagavato arahato sammāsambuddhassa (×3)**

**Literal:** Homage to that Blessed One, Arahant, Perfectly Self-Awakened One  
**Faithful:** Homage to the Blessed One, the Arahant, the Perfectly Self-Awakened One.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`namo`** | `(ind)` homage, reverence (to); **[√nam + as + o]** |
| **`tassa`** | `(dem pron masc dat sg)` to that, to him; **[ta]** |
| **`bhagavato`** | `(masc dat sg)` to the Blessed One; **[√bhaj > bhag + a + vant]** |
| **`arahato`** | `(masc dat sg)` to the Arahant, to the Worthy One; **[√arah + ant]** |
| **`sammāsambuddhassa`** | `(masc dat sg comp)` to the Perfectly Self-Awakened One; **[sammā + sambuddha]** |
| ↳ **`sammā`** | `(ind comp)` perfectly, rightly; **[sammā]** |
| ↳ **`sambuddhassa`** | `(masc dat sg)` to the self-awakened one; **[saṁ + √budh + ta]** |

**Buddhaṁ Dhammaṁ Saṅghaṁ namassāmi.**

**Literal:** [The] Buddha, [the] Dhamma, [the] Saṅgha I revere.  
**Faithful:** I pay homage to the Buddha, the Dhamma and the Saṅgha.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`buddhaṁ`** | `(masc acc sg)` Buddha, Awakened One; **[√budh + ta]** |
| **`dhammaṁ`** | `(masc acc sg)` Dhamma, teaching; **[√dhar + ma]** |
| **`saṅghaṁ`** | `(masc acc sg)` Saṅgha, community; **[saṁ + √ghaṭ + a]** |
| **`namassāmi`** | `(1st sg pres act indic)` I revere, I venerate, I pay homage to; **[√namass + a + mi]** |

**Vinayo sāsanassa āyū'ti.**

**Literal:** [The] Vinaya [is] of [the] dispensation [the] life, thus.  
**Faithful:** Vinaya is the life of the religion.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`vinayo`** | `(masc nom sg)` Vinaya, discipline, training; **[vi + √nī > nay + a]** |
| **`sāsanassa`** | `(nt gen sg)` of the dispensation, of the religion, of the teaching; **[√sās + ana]** |
| **`āyū'ti`** | `(sandhi)` [*āyu* (nt nom sg) life, lengthened before *iti* (ind), closing the quotation] life; **[ā + √i > ay + u; iti]** |

**Karotu me āyasmā okāsaṁ ahan-taṁ vattukāmo.**

**Literal:** May make for me [the] venerable one [an] opportunity; I that [am] wishing to speak.  
**Faithful:** I ask for permission from the ven. one: I wish to speak about the Vinaya.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`karotu`** | `(3rd sg pres act imperat)` may he make, may he give; **[√kar + o + tu]** |
| **`me`** | `(1st sg dat)` for me, to me; **[ahaṁ]** |
| **`āyasmā`** | `(masc nom sg)` [3rd person as polite address] the venerable one; **[ā + √i > ay + as + mant]** |
| **`okāsaṁ`** | `(masc acc sg)` opportunity, permission, leave; **[ava + √kās + a]** |
| **`ahan-taṁ`** | `(sandhi)` [*ahaṁ* (1st sg nom) I + *taṁ* (dem pron masc acc sg) that, i.e. the Vinaya, object of *vattukāmo*; the parallel at *Kd 2:16.1* has *taṁ* as "you" (2nd sg acc)] I ... that; **[ahaṁ; ta]** |
| **`vattukāmo`** | `(adj masc nom sg comp)` wishing to speak; **[vattuṁ + kāma]** |
| ↳ **`vattu`** | `(inf comp)` [*vattuṁ* in the compound] to speak; **[√vad + tuṁ]** |
| ↳ **`kāmo`** | `(adj masc nom sg)` wishing, wanting; **[√kam > kām + a]** |

> Reply:

**Karomi āyasmato okāsaṁ.**

**Literal:** I make for [the] venerable one [an] opportunity.  
**Faithful:** I give you the opportunity, venerable.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`karomi`** | `(1st sg pres act indic)` I make, I give; **[√kar > karo + mi]** |
| **`āyasmato`** | `(masc dat sg)` for the venerable one, to the venerable one; **[ā + √i > ay + as + mant]** |
| **`okāsaṁ`** | `(masc acc sg)` opportunity, permission, leave; **[ava + √kās + a]** |

*Kd 2:16.1*
