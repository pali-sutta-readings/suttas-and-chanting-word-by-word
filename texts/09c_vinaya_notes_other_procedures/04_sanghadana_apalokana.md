# Saṅghadāna-apalokana

*Sharing Saṅghadāna*

> After *saṅghadāna* is offered, a bhikkhu other than the senior *Thera* recites:

**Yagghe bhante saṅgho jānātu.**

**Literal:** Come now, venerable sirs, [the] Community may know.  
**Faithful:** May the Saṅgha hear me.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`yagghe`** | `(ind)` [calling for attention] come now!, see now!; **[yaṁ + gha > ghe]** |
| **`bhante`** | `(masc voc pl)` venerable sirs; **[√bhū > bhava + nta + e]** |
| **`saṅgho`** | `(masc nom sg)` Saṅgha, community; **[saṁ + √ghaṭ + a]** |
| **`jānātu`** | `(3rd sg pres act imperat)` may it know, let it know; **[√ñā > jā + nā + tu]** |

**Ayaṁ paṭhama-bhāgo therassa pāpuṇāti.**

**Literal:** This first portion to [the] elder reaches.  
**Faithful:** The first portion (of this offering) goes to the Elder.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`ayaṁ`** | `(dem pron masc nom sg)` this; **[ima]** |
| **`paṭhama-bhāgo`** | `(masc nom sg comp)` first portion, first share; **[paṭhama + bhāga]** |
| ↳ **`paṭhama`** | `(ord comp)` first; **[pa + tama > ṭhama]** |
| ↳ **`bhāgo`** | `(masc nom sg)` portion, share; **[√bhaj > bhag > bhāg + a]** |
| **`therassa`** | `(masc dat sg)` [dative with *pāpuṇāti*] to the elder; **[√ṭhā > thā + ira > thera]** |
| **`pāpuṇāti`** | `(3rd sg pres act indic)` reaches, falls to, goes to; **[pa + √ap + uṇā + ti]** |

**Variant:** for a Mahāthera: *therassa* → *mahātherassa*  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`mahātherassa`** | `(masc dat sg comp)` to the great elder; **[mahā + thera]** |
| ↳ **`mahā`** | `(adj comp)` great; **[√mah + nta + ā]** |
| ↳ **`therassa`** | `(masc dat sg)` to the elder; **[√ṭhā > thā + ira > thera]** |

**Avasesā bhāgā amhākañc'eva pāpuṇanti.**

**Literal:** [The] remaining portions to us and indeed reach,  
**Faithful:** The remainder is for the rest of us here: for the bhikkhus, sīladharās, sāmaṇeras and lay people.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`avasesā`** | `(adj masc nom pl)` remaining, the rest of; **[ava + √sis > ses + a]** |
| **`bhāgā`** | `(masc nom pl)` portions, shares; **[√bhaj > bhag > bhāg + a]** |
| **`amhākañc'eva`** | `(sandhi)` [*amhākaṁ* (1st pl dat) to us + *ca* (ind) and + *eva* (ind) indeed] and indeed to us; **[ahaṁ; ca; eva]** |
| **`pāpuṇanti`** | `(3rd pl pres act indic)` reach, fall to, go to; **[pa + √ap + uṇā + nti]** |

**Bhikkhūnañca sīladharānaṁ sāmaṇerānaṁ gahaṭṭhānaṁ**

**Literal:** to [the] bhikkhus and, to [the] sīladharās, to [the] novices, to [the] householders.  
**Faithful:** (continued)  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`bhikkhūnañca`** | `(sandhi)` [*bhikkhūnaṁ* (masc dat pl) to the bhikkhus + *ca* (ind) and] and to the bhikkhus; **[√bhikkh + u; ca]** |
| **`sīladharānaṁ`** | `(fem dat pl comp)` [*sīladharā*: title of the nuns of the Ajahn Chah communities in Britain; not in DPD] to the sīladharās, to the nuns; **[sīla + dhara + ā]** |
| ↳ **`sīla`** | `(nt comp)` virtue, ethical conduct; **[√sīl + a]** |
| ↳ **`dharānaṁ`** | `(fem dat pl)` to those who hold; **[√dhar + a + ā]** |
| **`sāmaṇerānaṁ`** | `(masc dat pl)` to the novices; **[√sam > sām + aṇa + era]** |
| **`gahaṭṭhānaṁ`** | `(masc dat pl comp)` to the householders, to lay people; **[gaha + ṭha]** |
| ↳ **`gaha`** | `(nt comp)` house, home; **[√gah + a]** |
| ↳ **`ṭṭhānaṁ`** | `(masc dat pl)` [*ṭha* with *ṭ* doubled after the first member] living (in), staying (in); **[√ṭhā + a]** |

**Te yathāsukhaṁ paribhuñjantu.**

**Literal:** They as [they] please may partake.  
**Faithful:** May they partake of it as they please.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`te`** | `(dem pron masc nom pl)` they; **[ta]** |
| **`yathāsukhaṁ`** | `(ind)` as one likes, as is comfortable; **[yathā + sukha + aṁ]** |
| **`paribhuñjantu`** | `(3rd pl pres act imperat)` may they use, may they partake of; **[pari + √bhuj > bhuñja + ntu]** |

> The Saṅgha responds:

**Sādhu.**

**Literal:** Good.  
**Faithful:** It is good.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`sādhu`** | `(ind)` it is good, good, well; **[√sādh + u]** |
