# Nissaya

*Dependence*

> Before the Rains Retreat or the Winter Retreat, individually or with the whole community, the bhikkhu asks for dependence:

**Ācariyo me bhante hohi,**

**Literal:** Teacher my, venerable sir, be,  
**Faithful:** Ven. sir, may you be my teacher.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`ācariyo`** | `(masc nom sg)` teacher, religious leader; **[ā + √car + iya]** |
| **`me`** | `(1st sg gen)` my; **[ahaṁ]** |
| **`bhante`** | `(masc voc sg)` venerable sir; **[√bhū > bhava + nta + e]** |
| **`hohi`** | `(2nd sg pres act imperat)` be!, become!; **[√hū > ho + hi]** |

**āyasmato nissāya vacchāmi. (×3)**

**Literal:** [On the] venerable one depending I shall live.  
**Faithful:** I shall stay dependent on the ven. one.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`āyasmato`** | `(masc gen sg)` [genitive with *nissāya*] on the venerable one; **[ā + √i > ay + as + mant]** |
| **`nissāya`** | `(abs)` depending on, relying on, supported by; **[ni + √si > sāy + ya]** |
| **`vacchāmi`** | `(1st sg fut act indic)` I shall live, I shall stay; **[√vas + a + ssa > vaccha + mi]** |

> The Ācariya:

**Sādhu, lahu, opāyikaṁ, paṭirūpaṁ,**

**Literal:** Good, easy, fitting, suitable,  
**Faithful:** It is good; ...convenient; ...suitable; ...proper; ... you should endeavour to conduct yourself in a good manner.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`sādhu`** | `(ind)` [each word is one of the replies allowed in *Kd 1:32.2*] it is good, good, well; **[√sādh + u]** |
| **`lahu`** | `(adj nt nom sg)` easy, light, convenient; **[lahu, no root in DPD]** |
| **`opāyikaṁ`** | `(adj nt nom sg)` fitting, suitable; **[opāyika, no root in DPD]** |
| **`paṭirūpaṁ`** | `(adj nt nom sg)` suitable, appropriate, proper; **[pati + √rūp + a]** |

**pāsādikena sampādehi.**

**Literal:** With [what is] pleasing strive to accomplish [your duties].  
**Faithful:** (continued)  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`pāsādikena`** | `(adj nt instr sg)` [instrumental of manner] in a pleasing way, in a way that inspires confidence; **[pa + √sad > sāde + a + ika]** |
| **`sampādehi`** | `(2nd sg pres caus act imperat)` strive to accomplish!, press on!; **[saṁ + √pad > pāde + hi]** |

*Kd 1:32.2*

> The bhikkhu:

**Sādhu bhante. Ajja-t-agge-dāni thero mayhaṁ bhāro, aham-pi therassa bhāro. (×3)**

**Literal:** Good, venerable sir. From today onwards now [the] elder [is] my burden, I too [am the] elder's burden.  
**Faithful:** It is good, ven. sir. From this day onwards the Elder will be my burden and I shall be the burden of the Elder.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`sādhu`** | `(ind)` it is good, good, well; **[√sādh + u]** |
| **`bhante`** | `(masc voc sg)` venerable sir; **[√bhū > bhava + nta + e]** |
| **`ajja-t-agge-dāni`** | `(sandhi)` [*ajja* (ind) today + *t* (sandhi consonant) + *agge* (nt loc sg) from the beginning + *dāni* (ind) now; *ajjatagge*: from today onwards] from this day onwards now; **[ima + jja; t; agga; ima + dāni]** |
| **`thero`** | `(masc nom sg)` the elder, senior monk; **[√ṭhā > thā + ira > thera]** |
| **`mayhaṁ`** | `(1st sg gen)` my, of me; **[ahaṁ]** |
| **`bhāro`** | `(masc nom sg)` burden, responsibility, load; **[√bhar > bhār + a]** |
| **`aham-pi`** | `(sandhi)` [*ahaṁ* (1st sg nom) I + *pi* (ind) also] I too; **[ahaṁ; pi]** |
| **`therassa`** | `(masc gen sg)` of the elder, the elder's; **[√ṭhā > thā + ira > thera]** |
| **`bhāro`** | `(masc nom sg)` burden, responsibility, load; **[√bhar > bhār + a]** |
