# Namo-kāra-aṭṭhaka

*The Homage Octet*

**Namo arahato sammā**

**Literal:** Homage to [the] Arahant, [the] Perfectly  
**Faithful:** Homage to the Arahant, the Perfectly  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`namo`** | `(ind)` homage, reverence (to); **[√nam + as + o]** |
| **`arahato`** | `(masc dat sg)` to the Arahant, to the Worthy One; **[√arah + ant]** |
| **`sammā`** | `(ind)` perfectly, rightly; **[sammā]** |

**Sambuddhassa mahesino**

**Literal:** Self-Awakened One, [the] great sage  
**Faithful:** Self-Awakened One, the great sage;  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`sambuddhassa`** | `(masc dat sg)` to the Self-Awakened One; **[saṁ + √budh + ta]** |
| **`mahesino`** | `(masc dat sg comp)` to the great sage; **[mahā + isi]** |
| ↳ **`mahā`** | `(adj comp)` great; **[√mah + nta + ā]** |
| ↳ **`isino`** | `(masc dat sg)` [*isi*, merged with *mahā* as *mahesi*] to the sage, to the seer; **[isi, no root in DPD]** |

**Svākkhātass'eva ten'idha**

**Literal:** Well proclaimed indeed by him here  
**Faithful:** well proclaimed indeed by him here;  

| Word | Analysis & Meaning |
| :--- | :--- |

| **`ten'idha`** | `(sandhi)` [*tena* (dem pron masc instr sg) + *idha* (adv)] by him here; **[ta + ima + dha]** |

**Ratanattayassa sādhukaṁ**

**Tassa vatthuttayassa-pi**

**Literal:** To that triple object too  
**Faithful:** to that threefold refuge too.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`tassa`** | `(dem pron nt dat sg)` to that; **[ta]** |
| **`vatthuttayassa-`** | `(nt dat sg comp)` [before *pi*] to the triple object, to the Triple Gem; **[vatthu + taya]** |
| ↳ **`vatthu`** | `(nt comp)` object, basis; **[√vas + tu]** |
| ↳ **`ttayassa-`** | `(nt dat sg)` [*tayassa*, with *t* doubled] to the triad; **[ti > tay + a]** |
| **`pi`** | `(ind)` too, also; **[pi]** |
