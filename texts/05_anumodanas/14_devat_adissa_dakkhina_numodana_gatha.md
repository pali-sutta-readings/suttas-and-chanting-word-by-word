# Devat'ādissa-dakkhiṇā'numodanā-gāthā

*Verses of Thanks for an Offering Dedicated to the Devas*

**Yasmiṁ padese kappeti vāsaṁ paṇḍita-jātiyo**

**Literal:** In which place makes dwelling a wise-natured [person],  
**Faithful:** In whatever place a wise person makes his dwelling,  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`yasmiṁ`** | `(rel pron masc loc sg)` in which, in whatever; **[ya]** |
| **`padese`** | `(masc loc sg)` in a place, in a region; **[pa + √dis > des + a]** |
| **`kappeti`** | `(3rd sg pres act indic)` makes, sets up (a dwelling); **[√kapp + e + ti]** |
| **`vāsaṁ`** | `(masc acc sg)` dwelling, residence; **[√vas > vās + a]** |
| **`paṇḍita-jātiyo`** | `(masc nom sg comp)` one who is wise by nature, a wise person; **[paṇḍita + jātiya]** |
| ↳ **`paṇḍita`** | `(adj comp)` wise, learned; **[paṇḍita, no root in DPD]** |
| ↳ **`jātiyo`** | `(masc nom sg)` of the nature (of), of the kind (of); **[√jan > jā + ti + iya]** |

**Sīlavant'ettha bhojetvā saññate brahma-cārino**

**Literal:** the virtuous here having fed, the restrained, the holy-life-livers,  
**Faithful:** having fed there the virtuous, the restrained, those who live the holy life,  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`sīlavant'ettha`** | `(sandhi)` [sandhi of *sīlavante* (masc acc pl) + *ettha* (ind)] the virtuous, here; **[√sīl + a + vant + ima + ttha]** |
| **`bhojetvā`** | `(abs)` having fed; **[√bhuj > bhoje + tvā]** |
| **`saññate`** | `(pp masc acc pl)` the restrained, the self-controlled; **[saṁ + √yam > saññaṁ + ta]** |
| **`brahma-cārino`** | `(masc acc pl comp)` those who live the holy life; **[brahma + cārī]** |
| ↳ **`brahma`** | `(masc comp)` holy, sublime (life); **[√brah + ma]** |
| ↳ **`cārino`** | `(masc acc pl)` living, practising; **[√car > cār + ī]** |

**Yā tattha devatā āsuṁ tāsaṁ dakkhiṇam-ādise**

**Literal:** which there devas were, to them the offering he should dedicate.  
**Faithful:** he should dedicate the offering to whatever devas are there.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`yā`** | `(rel pron fem nom pl)` which, whatever; **[ya]** |
| **`tattha`** | `(ind)` there, in that place; **[ta + ttha]** |
| **`devatā`** | `(fem nom pl)` devas, deities; **[√div > dev + a + tā]** |
| **`āsuṁ`** | `(3rd pl aor act indic)` were, have been; **[a + √as + uṁ]** |
| **`tāsaṁ`** | `(dem pron fem dat pl)` to them, for them; **[ta]** |
| **`dakkhiṇam-ādise`** | `(sandhi)` [sandhi of *dakkhiṇaṁ* (fem acc sg) + *ādise* (3rd sg act opt)] should dedicate the offering; **[√dakkh + iṇā + ā + √dis + a + e]** |

**Tā pūjitā pūjayanti mānitā mānayanti naṁ**

**Tato naṁ anukampanti mātā puttaṁ va orasaṁ**

**Literal:** Then him they have compassion for, a mother son like own.  
**Faithful:** So they have compassion for him, as a mother for her own child.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`tato`** | `(ind)` [ablative of *ta* used adverbially] then, therefore; **[ta + to]** |
| **`naṁ`** | `(dem pron masc acc sg)` him; **[ta]** |
| **`anukampanti`** | `(3rd pl pres act indic)` have compassion (for), care (for); **[anu + √kamp + a + nti]** |
| **`mātā`** | `(fem nom sg)` mother; **[mātar, no root in DPD]** |
| **`puttaṁ`** | `(masc acc sg)` son, child; **[putta, no root in DPD]** |
| **`va`** | `(ind)` [short for *iva*] like, as; **[iva]** |
| **`orasaṁ`** | `(masc acc sg)` own, born of one's breast; **[ura > ora + as + a]** |

**Devatā'nukampito poso sadā bhadrāni passati**

**Literal:** Devas-cared-for person always good things sees.  
**Faithful:** A person cared for by the devas always sees good fortune.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`devatā'nukampito`** | `(pp masc nom sg comp)` cared for by the devas; **[devatā + anukampita]** |
| ↳ **`devatā`** | `(fem comp)` devas, deities; **[√div > dev + a + tā]** |
| ↳ **`'nukampito`** | `(pp masc nom sg)` [*anukampito* with *a-* elided] cared for, shown compassion; **[anu + √kamp + ita]** |
| **`poso`** | `(masc nom sg)` person, man; **[purisa > porisa > posa, no root in DPD]** |
| **`sadā`** | `(ind)` always; **[saṁ + dā]** |
| **`bhadrāni`** | `(nt acc pl)` good things, good fortune; **[√bhad + ra]** |
| **`passati`** | `(3rd sg pres act indic)` sees, experiences; **[√dis > passa + ti]** |
