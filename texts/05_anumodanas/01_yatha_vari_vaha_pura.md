# Yathā vāri-vahā pūrā

*Just as Rivers*

**Yathā vāri-vahā pūrā paripūrenti sāgaraṁ**

**Literal:** Just as water-carriers full fill up the ocean  
**Faithful:** Just as rivers, when full, fill up the ocean,  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`yathā`** | `(ind)` as, just as; **[ya + thā]** |
| **`vāri-vahā`** | `(masc nom pl comp)` water-carriers, rivers; **[vāri + vaha]** |
| ↳ **`vāri`** | `(nt comp)` water; **[vāri, no root in DPD]** |
| ↳ **`vahā`** | `(masc nom pl)` carriers, those that carry; **[√vah + a]** |
| **`pūrā`** | `(masc nom pl)` full, filled; **[√pūr + a]** |
| **`paripūrenti`** | `(3rd pl pres act indic)` fill up, fill completely; **[pari + √pūr > pūre + nti]** |
| **`sāgaraṁ`** | `(masc acc sg)` ocean, sea; **[sāgara, no root in DPD]** |

| **`upakappati`** | `(3rd sg pres act indic)` is of benefit (to), serves; **[upa + √kapp + a + ti]** |
