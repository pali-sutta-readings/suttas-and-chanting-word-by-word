# Tāyana-gāthā

*The Verses of Tāyana*

**Handa mayaṁ tāyana-gāthāyo bhaṇāmase**

**Literal:** Come now, we [the] Tāyana-verses let us recite  
**Faithful:** Now let us recite the verses of Tāyana.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`handa`** | `(interj)` come now, well then; **[handa]** |
| **`mayaṁ`** | `(1st pl nom)` we; **[ahaṁ]** |
| **`tāyana-gāthāyo`** | `(fem acc pl comp)` the verses of Tāyana; **[tāyana + gāthā]** |
| ↳ **`tāyana`** | `(masc comp)` Tāyana (name of a deva); **[√tā + y + ana]** |
| ↳ **`gāthāyo`** | `(fem acc pl)` verses; **[√gā + thā]** |
| **`bhaṇāmase`** | `(1st pl pres mid imperat)` let us recite, let us say; **[√bhaṇ + a + mase]** |
