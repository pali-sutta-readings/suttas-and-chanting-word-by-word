# Sīl'uddesa-pāṭha

*Passage for the Recitation of Virtue*

**Handa mayaṁ sīl'uddesa-pāṭhaṁ bhaṇāmase**

**Literal:** Come now, we [the] virtue-recitation-passage let us recite  
**Faithful:** Now let us recite the passage for the recitation of virtue.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`handa`** | `(interj)` come now, well then; **[handa]** |
| **`mayaṁ`** | `(1st pl nom)` we; **[ahaṁ]** |
| **`sīl'uddesa-pāṭhaṁ`** | `(masc acc sg comp)` passage for the recitation of virtue; **[sīla + uddesa + pāṭha]** |
| ↳ **`sīl'`** | `(nt comp)` virtue, ethical conduct; **[√sīl + a]** |
| ↳ **`uddesa`** | `(masc comp)` recitation, summary; **[ud + √dis > des + a]** |
| ↳ **`pāṭhaṁ`** | `(masc acc sg)` passage, text for recitation; **[√paṭh > pāṭh + a]** |
| **`bhaṇāmase`** | `(1st pl pres mid imperat)` let us recite, let us say; **[√bhaṇ + a + mase]** |
