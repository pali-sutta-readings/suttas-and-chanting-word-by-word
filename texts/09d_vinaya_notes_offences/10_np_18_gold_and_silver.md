# Nissaggiya Pācittiya 18

*Gold and Silver*

> To be forfeited to the Saṅgha only:

**Ahaṁ bhante rūpiyaṁ paṭiggahesiṁ,**

**Literal:** I, venerable sirs, money accepted;  
**Faithful:** Ven. sirs, I have accepted money.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`ahaṁ`** | `(1st sg nom)` I; **[ahaṁ]** |
| **`bhante`** | `(masc voc pl)` venerable sirs; **[√bhū > bhava + nta + e]** |
| **`rūpiyaṁ`** | `(nt acc sg)` money, silver, (silver) coin; **[√rūp + a + iya]** |
| **`paṭiggahesiṁ`** | `(1st sg aor act indic)` I accepted, I received; **[pati + √gah > gahe + siṁ]** |

**idaṁ me nissaggiyaṁ. Imāhaṁ saṅghassa nissajjāmi.**

**Literal:** this by me [is] to be forfeited. This I to [the] Community forfeit.  
**Faithful:** This is to be forfeited by me: I forfeit it to the Saṅgha.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`idaṁ`** | `(dem pron nt nom sg)` this; **[ima]** |
| **`me`** | `(1st sg instr)` [enclitic; agent of *nissaggiyaṁ*] by me; **[ahaṁ]** |
| **`nissaggiyaṁ`** | `(ptp nt nom sg)` to be forfeited, to be given up; **[nī + √sajj > sagg + iya]** |
| **`imāhaṁ`** | `(sandhi)` [*imaṁ* (dem pron nt acc sg) this + *ahaṁ* (1st sg nom) I] this I; **[ima; ahaṁ]** |
| **`saṅghassa`** | `(masc dat sg)` to the Community, to the Saṅgha; **[saṁ + √ghaṭ + a]** |
| **`nissajjāmi`** | `(1st sg pres act indic)` I forfeit, I give up, I hand over; **[nī + √sajj + a + mi]** |
