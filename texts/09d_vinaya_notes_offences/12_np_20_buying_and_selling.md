# Nissaggiya Pācittiya 20

*Buying and Selling*

**Ahaṁ bhante nānappakārakaṁ kayavikkayaṁ samāpajjiṁ,**

**Literal:** I, venerable sir, various-kinds-of buying-and-selling engaged in;  
**Faithful:** Ven. sir, I have engaged in various kinds of buying and selling.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`ahaṁ`** | `(1st sg nom)` I; **[ahaṁ]** |
| **`bhante`** | `(masc voc sg)` venerable sir; **[√bhū > bhava + nta + e]** |
| **`nānappakārakaṁ`** | `(adj masc acc sg comp)` [agrees with *kayavikkayaṁ*] of various kinds, manifold; **[nānā + pakāraka]** |
| ↳ **`nānā`** | `(ind comp)` various, different; **[nānā]** |
| ↳ **`pakārakaṁ`** | `(adj masc acc sg)` of a kind, in a certain way; **[pa + √kar > kār + a + ka]** |
| **`kayavikkayaṁ`** | `(masc acc sg comp)` buying and selling, trading; **[kaya + vikkaya]** |
| ↳ **`kaya`** | `(masc comp)` buying, purchase; **[√kī > kay + a]** |
| ↳ **`vikkayaṁ`** | `(masc acc sg)` selling, sale; **[vi + √kī > kay + a]** |
| **`samāpajjiṁ`** | `(1st sg aor act indic)` I engaged in, I undertook; **[saṁ + ā + √pad > pajja + iṁ]** |

**idaṁ me nissaggiyaṁ. Imāhaṁ āyasmato nissajjāmi.**

**Literal:** this by me [is] to be forfeited. This I to [the] venerable [one] forfeit.  
**Faithful:** This (gain) of mine is to be forfeited by me: I forfeit it to you.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`idaṁ`** | `(dem pron nt nom sg)` this; **[ima]** |
| **`me`** | `(1st sg instr)` [enclitic; agent of *nissaggiyaṁ*] by me; **[ahaṁ]** |
| **`nissaggiyaṁ`** | `(ptp nt nom sg)` to be forfeited, to be given up; **[nī + √sajj > sagg + iya]** |
| **`imāhaṁ`** | `(sandhi)` [*imaṁ* (dem pron nt acc sg) this + *ahaṁ* (1st sg nom) I] this I; **[ima; ahaṁ]** |
| **`āyasmato`** | `(masc dat sg)` to the venerable one, to you; **[ā + √i > ay + as + mant]** |
| **`nissajjāmi`** | `(1st sg pres act indic)` I forfeit, I give up, I hand over; **[nī + √sajj + a + mi]** |

**Variant:** forfeiting to a Saṅgha: *āyasmato* → *saṅghassa*  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`saṅghassa`** | `(masc dat sg)` to the Community, to the Saṅgha; **[saṁ + √ghaṭ + a]** |

**Variant:** forfeiting to a group of bhikkhus: *āyasmato* → *āyasmantānaṁ*  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`āyasmantānaṁ`** | `(masc dat pl)` to the venerable ones, to you; **[ā + √i > ay + as + mant]** |
