# Nissaggiya Pācittiya 19

*Monetary Exchange*

> To be forfeited to the Saṅgha only:

**Ahaṁ bhante nānappakārakaṁ rūpiyasaṁvohāraṁ samāpajjiṁ,**

**Literal:** I, venerable sirs, various-kinds-of money-dealing engaged in;  
**Faithful:** Ven. sirs, I have engaged in various kinds of trafficking with money.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`ahaṁ`** | `(1st sg nom)` I; **[ahaṁ]** |
| **`bhante`** | `(masc voc pl)` venerable sirs; **[√bhū > bhava + nta + e]** |
| **`nānappakārakaṁ`** | `(adj masc acc sg comp)` [agrees with *rūpiyasaṁvohāraṁ*] of various kinds, manifold; **[nānā + pakāraka]** |
| ↳ **`nānā`** | `(ind comp)` various, different; **[nānā]** |
| ↳ **`pakārakaṁ`** | `(adj masc acc sg)` of a kind, in a certain way; **[pa + √kar > kār + a + ka]** |
| **`rūpiyasaṁvohāraṁ`** | `(masc acc sg comp)` trading with money, money exchange; **[rūpiya + saṁvohāra]** |
| ↳ **`rūpiya`** | `(nt comp)` money, silver; **[√rūp + a + iya]** |
| ↳ **`saṁvohāraṁ`** | `(masc acc sg)` trading, dealing, transaction; **[saṁ + vi + ava + √har > hār + a]** |
| **`samāpajjiṁ`** | `(1st sg aor act indic)` I engaged in, I undertook; **[saṁ + ā + √pad > pajja + iṁ]** |

**idaṁ me nissaggiyaṁ. Imāhaṁ saṅghassa nissajjāmi.**

**Literal:** this by me [is] to be forfeited. This I to [the] Community forfeit.  
**Faithful:** This (money) is to be forfeited by me: I forfeit it to the Saṅgha.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`idaṁ`** | `(dem pron nt nom sg)` this; **[ima]** |
| **`me`** | `(1st sg instr)` [enclitic; agent of *nissaggiyaṁ*] by me; **[ahaṁ]** |
| **`nissaggiyaṁ`** | `(ptp nt nom sg)` to be forfeited, to be given up; **[nī + √sajj > sagg + iya]** |
| **`imāhaṁ`** | `(sandhi)` [*imaṁ* (dem pron nt acc sg) this + *ahaṁ* (1st sg nom) I] this I; **[ima; ahaṁ]** |
| **`saṅghassa`** | `(masc dat sg)` to the Community, to the Saṅgha; **[saṁ + √ghaṭ + a]** |
| **`nissajjāmi`** | `(1st sg pres act indic)` I forfeit, I give up, I hand over; **[nī + √sajj + a + mi]** |
