# Āpatti-paṭidesanā

*Confession of Offences*

> Thai formula. The junior bhikkhu is confessing. Junior bhikkhu:

**Ahaṁ bhante sambahulā nānā-vatthukāyo thullaccayāyo āpattiyo āpanno tā paṭidesemi.**

**Literal:** I, venerable sir, many different-based grave offences fallen into, those [I] confess.  
**Faithful:** I, ven. sir, having many times fallen into grave offences with different bases, these I confess.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`ahaṁ`** | `(1st sg nom)` I; **[ahaṁ]** |
| **`bhante`** | `(masc voc sg)` venerable sir; **[√bhū > bhava + nta + e]** |
| **`sambahulā`** | `(adj fem acc pl)` [agrees with *āpattiyo*] many, numerous; **[saṁ + √bah + u + la]** |
| **`nānā-vatthukāyo`** | `(adj fem acc pl comp)` [agrees with *āpattiyo*] with different bases, based on various grounds; **[nānā + vatthuka]** |
| ↳ **`nānā`** | `(ind comp)` different, various; **[nānā]** |
| ↳ **`vatthukāyo`** | `(adj fem acc pl)` based on, having a basis; **[√vas + tu + ka]** |
| **`thullaccayāyo`** | `(adj fem acc pl comp)` [agrees with *āpattiyo*; DPD has the noun *thullaccaya* (nt)] grave, of the class of grave offences; **[thulla + accaya]** |
| ↳ **`thulla`** | `(adj comp)` (of an offence) serious, grave; gross; **[√thūl > thull + a]** |
| ↳ **`accayāyo`** | `(adj fem acc pl)` [noun used adjectivally] offence, transgression; **[ati > aty > acc + √i > ay + a]** |
| **`āpattiyo`** | `(fem acc pl)` (vinaya) offences; **[ā + √pad + ti]** |
| **`āpanno`** | `(pp masc nom sg)` [agrees with *ahaṁ*] having fallen into, having committed; **[ā + √pad + na]** |
| **`tā`** | `(dem pron fem acc pl)` those, them; **[ta]** |
| **`paṭidesemi`** | `(1st sg pres caus act indic)` I confess, I acknowledge; **[pati + √dis > dese + mi]** |

> Senior bhikkhu:

**Passasi āvuso.**

**Literal:** [Do you] see, friend?  
**Faithful:** Do you see, friend?  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`passasi`** | `(2nd sg pres act indic)` (do) you see; **[√dis > passa + si]** |
| **`āvuso`** | `(ind)` friend; **[ā + √i > ay + as + mant + o]** |

> Junior bhikkhu:

**Āma bhante passāmi.**

**Literal:** Yes, venerable sir, [I] see.  
**Faithful:** Yes, ven. sir, I see.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`āma`** | `(ind)` yes, certainly; **[āma]** |
| **`bhante`** | `(masc voc sg)` venerable sir; **[√bhū > bhava + nta + e]** |
| **`passāmi`** | `(1st sg pres act indic)` I see; **[√dis > passa + mi]** |

> Senior bhikkhu:

**Āyatiṁ āvuso saṁvareyyāsi.**

**Literal:** In future, friend, [you] should restrain [yourself].  
**Faithful:** In future, friend, you should be restrained.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`āyatiṁ`** | `(ind)` in future; **[ā + √yat + i + iṁ]** |

| **`saṁvareyyāsi`** | `(2nd sg act opt)` you should restrain (yourself), you should be restrained; **[saṁ + √var + a + eyyāsi]** |

> Junior bhikkhu:

**Sādhu suṭṭhu bhante saṁvarissāmi. (×3)**

**Literal:** Good, well, venerable sir, [I] will restrain [myself].  
**Faithful:** It is well indeed, ven. sir. I shall be restrained.  

| Word | Analysis & Meaning |
| :--- | :--- |
