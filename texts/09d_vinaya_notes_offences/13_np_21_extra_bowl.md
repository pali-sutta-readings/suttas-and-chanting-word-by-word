# Nissaggiya Pācittiya 21

*Extra Bowl*

**Ayaṁ me bhante patto dasāhātikkanto nissaggiyo. Imāhaṁ āyasmato nissajjāmi.**

**Literal:** This by me, venerable sir, bowl, beyond ten days, [is] to be forfeited. This I to [the] venerable [one] forfeit.  
**Faithful:** This bowl, ven. sir, which has passed beyond the ten-day (limit), is to be forfeited by me: I forfeit it to you.

| :--- | :--- |
| **`ayaṁ`** | `(dem pron masc nom sg)` this; **[ima]** |
| **`me`** | `(1st sg instr)` [enclitic; agent of *nissaggiyo*] by me; **[ahaṁ]** |
| **`bhante`** | `(masc voc sg)` venerable sir; **[√bhū > bhava + nta + e]** |
| **`patto`** | `(masc nom sg)` alms bowl, bowl; **[√pā + ta]** |
| **`dasāhātikkanto`** | `(adj masc nom sg comp)` kept longer than ten days, past the ten-day (limit); **[dasāha + atikkanta]** |
| ↳ **`dasāha`** | `(nt comp)` ten days; **[dasa + aha]** |
| ↳ **`atikkanto`** | `(pp masc nom sg)` gone beyond, exceeded; **[ati + √kam + ta]** |
| **`nissaggiyo`** | `(ptp masc nom sg)` to be forfeited, to be given up; **[nī + √sajj > sagg + iya]** |
| **`imāhaṁ`** | `(sandhi)` [*imaṁ* (dem pron masc acc sg) this + *ahaṁ* (1st sg nom) I] this I; **[ima; ahaṁ]** |
| **`āyasmato`** | `(masc dat sg)` to the venerable one, to you; **[ā + √i > ay + as + mant]** |
| **`nissajjāmi`** | `(1st sg pres act indic)` I forfeit, I give up, I hand over; **[nī + √sajj + a + mi]** |

> For returning the bowl:

**Imaṁ pattaṁ āyasmato dammi.**

**Literal:** This bowl to [the] venerable [one] [I] give.  
**Faithful:** I give this bowl to you.
