# Pārisuddhi-uposatha

*Purity Uposatha: Three Bhikkhus*

> If there are only three bhikkhus then, after the preliminary duties and the general confession, one bhikkhu chants the *ñatti*:

**Suṇantu me bhante āyasmantā,**

**Literal:** May listen [to] me, venerable sirs, [the] venerable ones.  
**Faithful:** Let the ven. ones listen to me.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`suṇantu`** | `(3rd pl pres act imperat)` may (they) listen, let (them) hear; **[√su + ṇā + ntu]** |
| **`me`** | `(1st sg gen)` [genitive with a verb of hearing] to me, me; **[ahaṁ]** |
| **`bhante`** | `(masc voc pl)` venerable sirs; **[√bhū > bhava + nta + e]** |
| **`āyasmantā`** | `(masc nom pl)` [polite address] the venerable ones, you, sirs; **[ā + √i > ay + as + mant]** |

**ajj'uposatho paṇṇaraso,**

**Literal:** Today [is the] Uposatha, [the] fifteenth.  
**Faithful:** Today is an Observance day, which is a fifteenth (day of the fortnight).  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`ajj'uposatho`** | `(sandhi)` [*ajja* (ind) today + *uposatho* (masc nom sg) observance day] today [is the] observance day; **[ima + jja; upa + √vas + a + tha]** |
| **`paṇṇaraso`** | `(masc nom sg)` [in apposition to *uposatho*] (the) fifteenth (day of the fortnight); **[pañca + dasa]** |

**yad'āyasmantānaṁ pattakallaṁ, mayaṁ aññamaññaṁ pārisuddhi uposathaṁ kareyyāma.**

**Literal:** If for [the] venerable ones [it is the] right time, we with one another [the] purity Uposatha should do.  
**Faithful:** If it seems right to the ven. ones let us carry out the Observance with one another by way of entire purity.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`yad'āyasmantānaṁ`** | `(sandhi)` [*yadi* (ind) if + *āyasmantānaṁ* (masc dat pl) for the venerable ones] if for the venerable ones; **[yadi; ā + √i > ay + as + mant]** |
| **`pattakallaṁ`** | `(nt nom sg comp)` the right time, a suitable occasion; readiness; **[patta + kalla]** |
| ↳ **`patta`** | `(pp comp)` reached, arrived (at); **[pa + √ap + ta]** |
| ↳ **`kallaṁ`** | `(nt nom sg)` good time, suitable occasion; **[√kal + ya]** |
| **`mayaṁ`** | `(1st pl nom)` we; **[ahaṁ]** |
| **`aññamaññaṁ`** | `(pron masc acc sg)` [adverbial] with one another, mutually; **[aññaṁ + aññaṁ]** |
| **`pārisuddhi`** | `(fem comp)` [written apart by BM; compound with *uposathaṁ*] purity; **[pari > pāri + √sudh + ta + i]** |
| **`uposathaṁ`** | `(masc acc sg)` Uposatha, observance day ceremony; **[upa + √vas + a + tha]** |
| **`kareyyāma`** | `(1st pl act opt)` let us do, we should carry out; **[√kar + eyyāma]** |

**Variant:** when it is the 14th day: *paṇṇaraso* → *cātuddaso*  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`cātuddaso`** | `(adj masc nom sg)` [agrees with *uposatho*] fourteenth (day of the fortnight); **[catu > cātu + dasa + a]** |

**Variant:** the announcing bhikkhu is the most senior: *bhante* → *āvuso*  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`āvuso`** | `(ind)` friend, friends; **[ā + √i > ay + as + mant + o]** |

> Then, starting with the senior bhikkhu:

**Parisuddho ahaṁ āvuso, parisuddho'ti maṁ dhāretha. (×3)**

**Literal:** Pure [am] I, friends; as pure me [you] consider.  
**Faithful:** I, friends, am quite pure. Understand that I am quite pure.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`parisuddho`** | `(pp masc nom sg)` pure, (quite) pure (of offences); **[pari + √sudh + ta]** |
| **`ahaṁ`** | `(1st sg nom)` I; **[ahaṁ]** |
| **`āvuso`** | `(ind)` friend, friends; **[ā + √i > ay + as + mant + o]** |
| **`parisuddho'ti`** | `(sandhi)` [*parisuddho* (pp masc nom sg) pure + *iti* (ind), marking how one is regarded] as pure; **[pari + √sudh + ta; iti]** |
| **`maṁ`** | `(1st sg acc)` me; **[ahaṁ]** |
| **`dhāretha`** | `(2nd pl pres act imperat)` consider, hold (me as), accept; **[√dhar + e > dhāre + tha]** |

**Variant:** for each of the two junior bhikkhus: *āvuso* → *bhante*  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`bhante`** | `(masc voc pl)` venerable sirs; **[√bhū > bhava + nta + e]** |
