# Pārisuddhi-uposatha

*Purity Uposatha: Two Bhikkhus*

> Omit the *ñatti*. The senior bhikkhu declares purity first:

**Parisuddho ahaṁ āvuso, parisuddho'ti maṁ dhārehi. (×3)**

**Literal:** Pure [am] I, friend; as pure me [you] consider.  
**Faithful:** I, friend, am quite pure. Understand that I am quite pure.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`parisuddho`** | `(pp masc nom sg)` pure, (quite) pure (of offences); **[pari + √sudh + ta]** |
| **`ahaṁ`** | `(1st sg nom)` I; **[ahaṁ]** |
| **`āvuso`** | `(ind)` friend; **[ā + √i > ay + as + mant + o]** |
| **`parisuddho'ti`** | `(sandhi)` [*parisuddho* (pp masc nom sg) pure + *iti* (ind), marking how one is regarded] as pure; **[pari + √sudh + ta; iti]** |
| **`maṁ`** | `(1st sg acc)` me; **[ahaṁ]** |
| **`dhārehi`** | `(2nd sg pres act imperat)` consider, hold (me as), accept; **[√dhar + e > dhāre + hi]** |

**Variant:** for the junior: *āvuso* → *bhante*; *dhārehi* → *dhāretha*  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`bhante`** | `(masc voc sg)` venerable sir; **[√bhū > bhava + nta + e]** |
| **`dhāretha`** | `(2nd pl pres act imperat)` [plural of respect] consider, hold (me as), accept; **[√dhar + e > dhāre + tha]** |
