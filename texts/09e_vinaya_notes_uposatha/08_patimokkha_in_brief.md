# Reciting the Pāṭimokkha in Brief

> If the abbreviation is after the Pārājika rules, the chanter concludes with:

**Uddiṭṭhaṁ kho āyasmanto nidānaṁ.**

**Literal:** Recited indeed, venerable ones, [is the] introduction.  
**Faithful:** The introduction has been recited, venerable ones.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`uddiṭṭhaṁ`** | `(pp nt nom sg)` [agrees with *nidānaṁ*] recited; **[ud + √dis + ta]** |
| **`kho`** | `(ind)` indeed, surely; **[kho]** |
| **`āyasmanto`** | `(masc voc pl)` venerable ones; **[ā + √i > ay + as + mant]** |
| **`nidānaṁ`** | `(nt nom sg)` (vinaya) introduction (of the Pāṭimokkha); **[ni + √dā + ana]** |

**Tattha sabbeh'eva samaggehi sammoda-mānehi avivada-mānehi sikkhitabban'ti.**

**Faithful:** In this all should train, united, in friendly agreement, without dispute.
