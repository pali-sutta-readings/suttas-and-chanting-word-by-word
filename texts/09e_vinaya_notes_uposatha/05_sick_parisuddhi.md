# Pārisuddhi

*Sick Bhikkhus: Conveying Purity*

> The sick bhikkhu makes general confession, then:

**Pārisuddhiṁ dammi,**

**Literal:** [My] purity [I] give,  
**Faithful:** I give my purity.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`pārisuddhiṁ`** | `(fem acc sg)` (vinaya) purity; **[pari > pāri + √sudh + ta + i]** |
| **`dammi`** | `(1st sg pres act indic)` I give; **[√dā + āmi > dammi]** |

**pārisuddhiṁ me hara, pārisuddhiṁ me ārocehi.**

**Literal:** [the] purity for me carry, [the] purity for me announce.  
**Faithful:** Please convey purity for me (and) declare purity for me.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`pārisuddhiṁ`** | `(fem acc sg)` (vinaya) purity; **[pari > pāri + √sudh + ta + i]** |
| **`me`** | `(1st sg dat)` for me, on my behalf; **[ahaṁ]** |
| **`hara`** | `(2nd sg pres act imperat)` carry, convey, take; **[√har + a]** |
| **`pārisuddhiṁ`** | `(fem acc sg)` (vinaya) purity; **[pari > pāri + √sudh + ta + i]** |
| **`me`** | `(1st sg dat)` for me, on my behalf; **[ahaṁ]** |
| **`ārocehi`** | `(2nd sg pres caus act imperat)` announce, declare, inform (the Saṅgha); **[ā + √ruc > roce + hi]** |

**Variant:** the sick bhikkhu is the junior: *hara* → *haratha*; *ārocehi* → *ārocetha*  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`haratha`** | `(2nd pl pres act imperat)` [plural of respect] carry, convey, take; **[√har + a + tha]** |
| **`ārocetha`** | `(2nd pl pres caus act imperat)` [plural of respect] announce, declare, inform; **[ā + √ruc > roce + tha]** |

> The sick bhikkhu's (e.g. Uttaro's) purity is conveyed after the Pātimokkha:

**Āyasmā bhante uttaro bhikkhu gilāno, parisuddho'ti paṭijāni,**

**Literal:** [The] venerable, venerable sirs, Uttaro, [the] bhikkhu, sick, as pure acknowledged [himself];  
**Faithful:** Ven. sirs, Uttaro Bhikkhu who is sick acknowledges that he is pure.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`āyasmā`** | `(masc nom sg)` the venerable; **[ā + √i > ay + as + mant]** |
| **`bhante`** | `(masc voc pl)` venerable sirs; **[√bhū > bhava + nta + e]** |
| **`uttaro`** | `(masc nom sg)` [example name; substitute the actual name] Uttaro; **[proper name]** |
| **`bhikkhu`** | `(masc nom sg)` [in apposition to *uttaro*] the bhikkhu, the monk; **[√bhikkh + u]** |
| **`gilāno`** | `(adj masc nom sg)` [agrees with *uttaro*] sick, ill; **[√gilā + ana]** |
| **`parisuddho'ti`** | `(sandhi)` [*parisuddho* (pp masc nom sg) pure + *iti* (ind), marking how one is regarded] as pure; **[pari + √sudh + ta; iti]** |
| **`paṭijāni`** | `(3rd sg aor act indic)` acknowledged, declared, assented; **[pati + √ñā > jān + i]** |

**parisuddho'ti taṁ saṅgho dhāretu.**

**Literal:** as pure him [the] Community may consider.  
**Faithful:** May the Saṅgha hold him to be pure.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`parisuddho'ti`** | `(sandhi)` [*parisuddho* (pp masc nom sg) pure + *iti* (ind), marking how one is regarded] as pure; **[pari + √sudh + ta; iti]** |
| **`taṁ`** | `(dem pron masc acc sg)` him; **[ta]** |
| **`saṅgho`** | `(masc nom sg)` Community, Saṅgha; **[saṁ + √ghaṭ + a]** |
| **`dhāretu`** | `(3rd sg pres act imperat)` may (it) consider, may (it) hold (him as), may (it) accept; **[√dhar + e > dhāre + tu]** |

**Variant:** the conveying bhikkhu is senior to the sick bhikkhu: *Āyasmā bhante uttaro bhikkhu* → *Uttaro bhante bhikkhu*
