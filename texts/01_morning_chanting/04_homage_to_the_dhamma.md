# Dhammābhitthuti

*Homage to the Dhamma*

**Handa mayaṁ dhammābhitthutiṁ karomase**

**Literal:** Come now, we high praise of [the] Dhamma let us make  
**Faithful:** Now let us chant in high praise of the Dhamma.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`handa`** | `(interj)` come now, well then; **[handa]** |
| **`mayaṁ`** | `(1st pl nom)` we; **[ahaṁ]** |
| **`dhammābhitthutiṁ`** | `(fem acc sg comp)` high praise of the Dhamma; **[dhamma + abhitthuti]** |
| ↳ **`dhamma`** | `(masc comp)` Dhamma; **[√dhar + ma]** |
| ↳ **`abhitthutiṁ`** | `(fem acc sg)` high praise; **[abhi + √thu + ti]** |
| **`karomase`** | `(1st pl pres mid imperat)` let us make, let us do; **[√kar + o + mase]** |

**Yo so svākkhāto bhagavatā dhammo**

**Literal:** Which that well proclaimed by [the] Blessed One Dhamma  
**Faithful:** The Dhamma, well proclaimed by the Blessed One,  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`yo`** | `(rel pron masc nom sg)` which, that which; **[ya]** |
| **`so`** | `(dem pron masc nom sg)` that; **[ta]** |
| **`svākkhāto`** | `(adj masc nom sg)` well proclaimed, well taught; **[su > sv + ā + √khā + ta]** |
| **`bhagavatā`** | `(masc instr sg)` by the Blessed One; **[√bhaj > bhag + a + vant]** |
| **`dhammo`** | `(masc nom sg)` Dhamma, teaching; **[√dhar + ma]** |

**Sandiṭṭhiko akāliko ehipassiko opanayiko**

**Literal:** Directly visible, timeless, inviting to come and see, leading onward  
**Faithful:** visible here and now, timeless, inviting one to come and see, leading onward,  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`sandiṭṭhiko`** | `(adj masc nom sg)` directly visible, evident here and now; **[saṁ + √dis + ti + ka]** |
| **`akāliko`** | `(adj masc nom sg)` timeless, immediate; **[na + √kal + a + ika]** |
| **`ehipassiko`** | `(masc nom sg comp)` inviting one to come and see, open to inspection; **[ehi + passa + ika]** |
| ↳ **`ehi`** | `(2nd sg pres act imperat)` come!; **[√i + a + hi]** |
| ↳ **`passa`** | `(2nd sg pres act imperat)` see!; **[√dis + a (passa)]** |
| **`opanayiko`** | `(adj masc nom sg)` leading onward, leading towards [the goal]; **[upa + √nī + a + ika]** |

**Paccattaṁ veditabbo viññūhi**

**Literal:** Personally to be known by [the] wise  
**Faithful:** to be experienced by the wise for themselves:  

| Word | Analysis & Meaning |
| :--- | :--- |

| **`veditabbo`** | `(ptp masc nom sg)` to be known, to be experienced; **[√vid + e + itabba]** |
| **`viññūhi`** | `(masc instr pl)` by the wise, by the discerning; **[vi + √ñā + ū]** |
