# Saṅghābhitthuti

*Homage to the Saṅgha*

**Handa mayaṁ saṅghābhitthutiṁ karomase**

**Literal:** Come now, we high praise of [the] Saṅgha let us make  
**Faithful:** Now let us chant in high praise of the Saṅgha.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`handa`** | `(interj)` come now, well then; **[handa]** |
| **`mayaṁ`** | `(1st pl nom)` we; **[ahaṁ]** |
| **`saṅghābhitthutiṁ`** | `(fem acc sg comp)` high praise of the Saṅgha; **[saṅgha + abhitthuti]** |
| ↳ **`saṅgha`** | `(masc comp)` Saṅgha; **[saṁ + √ghaṭ + a]** |
| ↳ **`abhitthutiṁ`** | `(fem acc sg)` high praise; **[abhi + √thu + ti]** |
| **`karomase`** | `(1st pl pres mid imperat)` let us make, let us do; **[√kar + o + mase]** |
