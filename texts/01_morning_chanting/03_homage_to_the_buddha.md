# Buddhābhitthuti

*Homage to the Buddha*

**Handa mayaṁ buddhābhitthutiṁ karomase**

**Literal:** Come now, we high praise of [the] Buddha let us make  
**Faithful:** Now let us chant in high praise of the Buddha.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`handa`** | `(interj)` come now, well then; **[handa]** |
| **`mayaṁ`** | `(1st pl nom)` we; **[ahaṁ]** |
| **`buddhābhitthutiṁ`** | `(fem acc sg comp)` high praise of the Buddha; **[buddha + abhitthuti]** |
| ↳ **`buddha`** | `(masc comp)` Buddha; **[√budh + ta]** |
| ↳ **`abhitthutiṁ`** | `(fem acc sg)` high praise; **[abhi + √thu + ti]** |
| **`karomase`** | `(1st pl pres mid imperat)` let us make, let us do; **[√kar + o + mase]** |

**Yo so tathāgato arahaṁ sammāsambuddho**

**Faithful:** He who is the Tathāgata, the Arahant, the Perfectly Self-Awakened One,

| :--- | :--- |
| **`yo`** | `(rel pron masc nom sg)` who, he who; **[ya]** |
| **`so`** | `(dem pron masc nom sg)` that, he; **[ta]** |
| **`tathāgato`** | `(masc nom sg comp)` Tathāgata, one who has arrived at the truth; **[tathā + gata / tatha + āgata]** |
| ↳ **`tathā`** | `(ind comp)` thus, so; **[ta + thā]** |
| ↳ **`gato`** | `(pp masc nom sg)` gone (or āgato: come); **[√gam + ta]** |
| **`arahaṁ`** | `(masc nom sg)` Arahant, Worthy One; **[√arah + ant]** |
| **`sammāsambuddho`** | `(masc nom sg comp)` Perfectly Self-Awakened One; **[sammā + sambuddha]** |
| ↳ **`sammā`** | `(ind comp)` perfectly, rightly; **[sammā]** |
| ↳ **`sambuddho`** | `(masc nom sg)` self-awakened one; **[saṁ + √budh + ta]** |
