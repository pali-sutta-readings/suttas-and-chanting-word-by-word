# Pavāraṇā

*Inviting Admonition: Two Bhikkhus*

> Preliminary duties, but no *ñatti*, then each bhikkhu in order of Rains:

**Ahaṁ bhante āyasmantaṁ pavāremi.**

**Literal:** I, venerable sir, [the] venerable one invite.  
**Faithful:** Ven. sir, I invite admonition from the ven. one.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`ahaṁ`** | `(1st sg nom)` I; **[ahaṁ]** |
| **`bhante`** | `(masc voc sg)` venerable sir; **[√bhū > bhava + nta + e]** |
| **`āyasmantaṁ`** | `(masc acc sg)` [polite address] the venerable one, you; **[ā + √i > ay + as + mant]** |
| **`pavāremi`** | `(1st sg pres act indic)` I invite (admonition from), I make the Pavāraṇā (to); **[pa + √var + e + mi]** |

**Diṭṭhena vā sutena vā parisaṅkāya vā, vadatu maṁ āyasmā anukampaṁ upādāya.**

**Literal:** By [what is] seen or by [what is] heard or by suspicion or, may speak [to] me [the] venerable one, compassion taking up.  
**Faithful:** According to what has been seen, heard or suspected, may the ven. one instruct me out of compassion.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`diṭṭhena`** | `(pp nt instr sg)` by what has been seen; **[√dis + ta]** |
| **`vā`** | `(ind)` or; **[vā]** |
| **`sutena`** | `(pp nt instr sg)` by what has been heard; **[√su + ta]** |
| **`vā`** | `(ind)` or; **[vā]** |
| **`parisaṅkāya`** | `(fem instr sg)` by suspicion; **[pari + √saṅk + ā]** |
| **`vā`** | `(ind)` or; **[vā]** |
| **`vadatu`** | `(3rd sg pres act imperat)` may (he) speak (to), may (he) tell, may (he) instruct; **[√vad + a + tu]** |
| **`maṁ`** | `(1st sg acc)` me; **[ahaṁ]** |
| **`āyasmā`** | `(masc nom sg)` [polite address] the venerable one, you; **[ā + √i > ay + as + mant]** |
| **`anukampaṁ`** | `(fem acc sg)` compassion, concern; **[anu + √kamp + ā]** |
| **`upādāya`** | `(abs)` out of, on account of; lit. taking up; **[upa + √ādā + ya]** |
