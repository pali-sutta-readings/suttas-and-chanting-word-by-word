# Sattāha-karaṇīya

*Seven-day Leave*

> One may take leave using one's own language, or the Pāli:

**Sattāha-karaṇīyaṁ kiccaṁ me-v-atthi tasmā mayā gantabbaṁ,**

**Literal:** [A] to-be-done-within-seven-days business for me there is, therefore by me [it is] to be gone,  
**Faithful:** I have an obligation which must be fulfilled within seven days. Therefore I have to go.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`sattāha-karaṇīyaṁ`** | `(ptp nt nom sg comp)` [agrees with *kiccaṁ*] to be done within seven days; **[sattāha + karaṇīya]** |
| ↳ **`sattāha`** | `(nt comp)` seven days, a week; **[satta + aha]** |
| ↳ **`karaṇīyaṁ`** | `(ptp nt nom sg)` to be done, must be done; **[√kar + aṇīya]** |
| **`kiccaṁ`** | `(nt nom sg)` obligation, duty, business; **[√kar > kir + tya]** |
| **`me-v-atthi`** | `(sandhi)` [*me* (1st sg dat/gen) for me + *-v-* (joining consonant) + *atthi* (3rd sg pres act indic) there is] I have, there is for me; **[ahaṁ + v + atthi (√as + ti)]** |
| **`tasmā`** | `(ind)` therefore; **[ta + smā]** |
| **`mayā`** | `(1st sg instr)` by me; **[ahaṁ]** |
| **`gantabbaṁ`** | `(ptp nt nom sg)` [impersonal; *mayā* is the agent] (it) should be gone, I must go; **[√gam + tabba]** |

**imasmiṁ sattāh'abbhantare nivattissāmi.**

**Literal:** in this seven-day interval I shall return.  
**Faithful:** I shall return within seven days.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`imasmiṁ`** | `(dem pron nt loc sg)` [agrees with *sattāh'abbhantare*] in this; **[ima]** |
| **`sattāh'abbhantare`** | `(nt loc sg comp)` within seven days, inside the seven-day period; **[sattāha + abbhantara]** |
| ↳ **`sattāh'`** | `(nt comp)` seven days, a week; **[satta + aha]** |
| ↳ **`abbhantare`** | `(nt loc sg)` inside, within, in the interior; **[abhi > abhy > abbh + anta + ra]** |
| **`nivattissāmi`** | `(1st sg fut act indic)` I shall return, I shall come back; **[ni + √vatt + a + issā + mi]** |

*Kd 3:5.4*
