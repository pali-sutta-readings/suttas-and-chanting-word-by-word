# Khamāpana-kamma

*Asking for Forgiveness*

> All community members kneel before the Ācariya, the most senior of them leading, with the offering tray at his side; all bow three times and stay bowed for the chanting. The leader prompts (*Na–*), then all chant together:

**Namo tassa bhagavato arahato sammāsambuddhassa (×3)**

**Literal:** Homage to that Blessed One, Arahant, Perfectly Self-Awakened One  
**Faithful:** Homage to the Blessed One, the Arahant, the Perfectly Self-Awakened One.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`namo`** | `(ind)` homage, reverence (to); **[√nam + as + o]** |
| **`tassa`** | `(dem pron masc dat sg)` to that, to him; **[ta]** |
| **`bhagavato`** | `(masc dat sg)` to the Blessed One; **[√bhaj > bhag + a + vant]** |
| **`arahato`** | `(masc dat sg)` to the Arahant, to the Worthy One; **[√arah + ant]** |
| **`sammāsambuddhassa`** | `(masc dat sg comp)` to the Perfectly Self-Awakened One; **[sammā + sambuddha]** |
| ↳ **`sammā`** | `(ind comp)` perfectly, rightly; **[sammā]** |
| ↳ **`sambuddhassa`** | `(masc dat sg)` to the self-awakened one; **[saṁ + √budh + ta]** |

> The leader holds up the tray, still bowed, and prompts (*Ā–*); all chant together:

**Āyasmante pamādena, dvārattayena kataṁ, sabbaṁ aparādhaṁ khamatu no bhante.**

**Literal:** [Towards the] venerable one through carelessness, by [the] three doors done, all wrong-doing may [he] forgive us, venerable sir.  
**Faithful:** Forgive us, ven. sir, for all wrong-doing done carelessly to the ven. one by way of the three doors.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`āyasmante`** | `(masc loc sg)` [locative of the person concerned] towards the venerable one, regarding the venerable one; **[ā + √i > ay + as + mant]** |
| **`pamādena`** | `(masc instr sg)` through carelessness, through negligence, heedlessness; **[pa + √mad > mād + a]** |
| **`dvārattayena`** | `(nt instr sg comp)` by way of the three doors (body, speech and mind); **[dvāra + taya]** |
| ↳ **`dvāra`** | `(nt comp)` door, gateway; **[√dvar > dvār + a]** |
| ↳ **`ttayena`** | `(nt instr sg)` [*taya* with *t* doubled after the first member] by the triad, by the group of three; **[ti > tay + a]** |
| **`kataṁ`** | `(pp masc acc sg)` [agrees with *aparādhaṁ*] done, committed; **[√kar + ta]** |
| **`sabbaṁ`** | `(pron masc acc sg)` [agrees with *aparādhaṁ*] all, every; **[sabba]** |
| **`aparādhaṁ`** | `(masc acc sg)` offence, wrong-doing, fault; **[apa + √rādh + a]** |
| **`khamatu`** | `(3rd sg pres act imperat)` [3rd person as polite address to the venerable one] may (he) forgive, may (he) pardon; **[√kham + a + tu]** |
| **`no`** | `(1st pl dat)` [enclitic] us, for us; **[ahaṁ]** |
| **`bhante`** | `(masc voc sg)` venerable sir; **[√bhū > bhava + nta + e]** |

> The leader offers the tray to the Ācariya. The Ācariya:

**Ahaṁ khamāmi, tumhehi pi me khamitabbaṁ.**

**Literal:** I forgive, by you also [to] me [it is] to be forgiven.  
**Faithful:** I forgive you. You should also forgive me.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`ahaṁ`** | `(1st sg nom)` I; **[ahaṁ]** |
| **`khamāmi`** | `(1st sg pres act indic)` I forgive, I pardon; **[√kham + a + mi]** |
| **`tumhehi`** | `(2nd pl instr)` by you; **[tumha]** |
| **`pi`** | `(ind)` also, too; **[pi]** |
| **`me`** | `(1st sg dat)` [enclitic; the one to be forgiven] me, to me; **[ahaṁ]** |
| **`khamitabbaṁ`** | `(ptp nt nom sg)` [impersonal; *tumhehi* is the agent] should be forgiven, should be pardoned; **[√kham + itabba]** |

**Variant:** a single community member asking: *tumhehi pi* → *tayā pi*  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`tayā`** | `(2nd sg instr)` by you; **[tvaṁ + ayā]** |
| **`pi`** | `(ind)` also, too; **[pi]** |

> The group stays bowed while the Ācariya gives his blessing:

**Evaṁ hotu evaṁ hotu,**

**Literal:** Thus may [it] be, thus may [it] be,  
**Faithful:** So be it, so be it.

**Yo ca pubbe pamajjitvā pacchā so nappamajjati,**

**Literal:** Who and formerly having been heedless, afterwards he is not heedless,  
**Faithful:** Whoever was heedless before and afterwards is heedless no more lights up this world, like the moon freed from a cloud.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`yo`** | `(rel pron masc nom sg)` who, whoever; **[ya]** |
| **`ca`** | `(ind)` and; **[ca]** |
| **`pubbe`** | `(ind)` formerly, before, in the past; **[pubba + e]** |
| **`pamajjitvā`** | `(abs)` having been heedless, having been negligent; **[pa + √mad + ya + itvā]** |
| **`pacchā`** | `(ind)` afterwards, later; **[paccha + ā]** |
| **`so`** | `(dem pron masc nom sg)` he, that one; **[ta]** |
| **`nappamajjati`** | `(3rd sg pres act indic)` [*na* + *pamajjati*, *p* doubled] is not heedless, is not negligent; **[na + pa + √mad + ya + ti]** |
