# Kaṭhina Anumodanā

*Approving the Kaṭhina*

> The recipient of the Kaṭhina:

**Atthataṁ bhante saṅghassa kaṭhinaṁ, dhammiko kaṭhinatthāro, anumodatha. (×3)**

**Literal:** Spread, venerable sirs, [is the] Community's Kaṭhina, lawful [is the] Kaṭhina-spreading, approve.  
**Faithful:** Ven. sirs, the Community's Kaṭhina has been spread; the spreading of the Kaṭhina is in accordance with the Dhamma. Please approve of it.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`atthataṁ`** | `(pp nt nom sg)` spread, laid out; **[ā + √thar + ta]** |
| **`bhante`** | `(masc voc pl)` venerable sirs; **[√bhū > bhava + nta + e]** |
| **`saṅghassa`** | `(masc gen sg)` of the Community, the Community's; **[saṁ + √ghaṭ + a]** |
| **`kaṭhinaṁ`** | `(nt nom sg)` Kaṭhina (the robe-making privileges after the Rains); **[kaṭhina, no root in DPD]** |
| **`dhammiko`** | `(adj masc nom sg)` lawful, legitimate, in accordance with the Dhamma; **[√dhar + ma + ika]** |
| **`kaṭhinatthāro`** | `(masc nom sg comp)` spreading of the Kaṭhina; **[kaṭhina + atthāra]** |
| ↳ **`kaṭhin'`** | `(nt comp)` Kaṭhina; **[kaṭhina, no root in DPD]** |
| ↳ **`atthāro`** | `(masc nom sg)` spreading, laying out; **[ā + √thar + a]** |
| **`anumodatha`** | `(2nd pl pres act imperat)` approve (of it), rejoice (in it); **[anu + √mud + a + tha]** |
