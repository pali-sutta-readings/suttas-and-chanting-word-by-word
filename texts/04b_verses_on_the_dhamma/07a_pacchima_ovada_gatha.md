# Pacchima-ovāda-gāthā

*The Buddha's Last Instruction*

**Handa dāni bhikkhave āmantayāmi vo**

**Literal:** Come-now now, bhikkhus, I-address you:  
**Faithful:** Come now, bhikkhus, I address you:  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`handa`** | `(interj)` come now, well then; **[handa]** |
| **`dāni`** | `(ind)` now; **[ima + dāni]** |
| **`bhikkhave`** | `(masc voc pl)` bhikkhus, monks; **[√bhikkh + u + ave]** |
| **`āmantayāmi`** | `(1st sg pres act indic)` I address, I tell; **[ā + √mant + aya + mi]** |
| **`vo`** | `(2nd pl acc)` you; **[tumha]** |

**Vaya-dhammā saṅkhārā**

**Literal:** decay-natured [are] formations;  
**Faithful:** all conditioned things are subject to passing away;  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`vaya-dhammā`** | `(adj masc nom pl comp)` subject to passing away, having the nature to decay; **[vaya + dhamma]** |
| ↳ **`vaya`** | `(masc comp)` passing away, decay, dissolution; **[vi + √i > ay + a]** |
| ↳ **`dhammā`** | `(adj masc nom pl)` having the nature (of), subject to; **[√dhar + ma]** |
| **`saṅkhārā`** | `(masc nom pl)` formations, conditioned things; **[saṁ + √kar > khār + a]** |

**Appamādena sampādethā'ti**

**Literal:** with-heedfulness strive-to-accomplish, thus.  
**Faithful:** strive on with heedfulness.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`appamādena`** | `(masc instr sg)` with heedfulness, with diligence; **[na > a + pa + √mad > mād + a]** |
| **`sampādethā'ti`** | `(sandhi)` [*sampādetha* (2nd pl pres act imperat), lengthened before *iti*, + *iti* (ind), closing the quotation] strive to accomplish, press on; **[saṁ + √pad > pād + e + tha; + iti]** |

**Ayaṁ tathāgatassa pacchimā vācā**

**Literal:** This [was] of-the-Tathāgata [the] last word.  
**Faithful:** This was the last word of the Tathāgata.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`ayaṁ`** | `(dem pron fem nom sg)` this; **[ima]** |
| **`tathāgatassa`** | `(masc gen sg comp)` of the Tathāgata; **[tathā + gata / tatha + āgata]** |
| ↳ **`tathā`** | `(ind comp)` thus, so; **[ta + thā]** |
| ↳ **`gatassa`** | `(masc gen sg)` gone (or *āgatassa*: come); **[√gam + ta]** |
| **`pacchimā`** | `(adj fem nom sg)` last, final; **[pacchā + ima]** |
| **`vācā`** | `(fem nom sg)` word, speech; **[√vac > vāc + ā]** |

*DN 16:6.7*
