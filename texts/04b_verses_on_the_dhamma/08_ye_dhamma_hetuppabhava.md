# Ye dhammā hetuppabhavā

*Verse on Things Arising from a Cause*

**Ye dhammā hetuppabhavā**

**Literal:** Which things [are] cause-arisen,  
**Faithful:** Whatever things arise from a cause,  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`ye`** | `(rel pron masc nom pl)` which, whatever; **[ya]** |
| **`dhammā`** | `(masc nom pl)` things, phenomena; **[√dhar + ma]** |
| **`hetuppabhavā`** | `(adj masc nom pl comp)` arising from a cause; **[hetu + pabhava]** |
| ↳ **`hetu`** | `(masc comp)` cause, reason; **[√hi > he + tu]** |
| ↳ **`ppabhavā`** | `(adj masc nom pl)` [*pabhava* with *p-* doubled in the compound] arising, originating; **[pa + √bhū > bhav + a]** |

**Tesaṁ hetuṁ tathāgato āha**

**Literal:** of-those [the] cause [the] Tathāgata has-told,  
**Faithful:** their cause the Tathāgata has told,  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`tesaṁ`** | `(dem pron masc gen pl)` of those, their; **[ta]** |
| **`hetuṁ`** | `(masc acc sg)` cause, reason; **[√hi > he + tu]** |
| **`tathāgato`** | `(masc nom sg comp)` Tathāgata, one who has arrived at the truth; **[tathā + gata / tatha + āgata]** |
| ↳ **`tathā`** | `(ind comp)` thus, so; **[ta + thā]** |
| ↳ **`gato`** | `(masc nom sg)` gone (or *āgato*: come); **[√gam + ta]** |
| **`āha`** | `(3rd sg perf act indic)` has said, has told; **[√ah + a]** |

**Tesañca yo nirodho**

**Literal:** and-of-those which [is the] cessation;  
**Faithful:** and also their cessation:  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`tesañca`** | `(sandhi)` [*tesaṁ* (dem pron masc gen pl) + *ca* (ind)] and of those; **[ta + ca]** |
| **`yo`** | `(rel pron masc nom sg)` which, whatever; **[ya]** |
| **`nirodho`** | `(masc nom sg)` cessation, ending; **[ni + √rudh > rodh + a]** |

**Evaṁ-vādī mahāsamaṇo'ti**

**Literal:** thus-speaking [is the] Great-Ascetic.  
**Faithful:** so teaches the Great Ascetic.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`evaṁ-vādī`** | `(adj masc nom sg comp)` speaking thus, one who teaches thus; **[evaṁ + vādī]** |
| ↳ **`evaṁ`** | `(adv comp)` thus, in this way; **[eva + aṁ]** |
| ↳ **`vādī`** | `(adj masc nom sg)` speaking, teaching; **[√vad > vād + ī]** |
| **`mahāsamaṇo'ti`** | `(masc nom sg comp)` [+ *iti* (ind), closing the verse] the Great Ascetic; **[mahā + samaṇa; + iti]** |
| ↳ **`mahā`** | `(adj comp)` great; **[√mah + nta + ā]** |
| ↳ **`samaṇo'ti`** | `(masc nom sg)` [*samaṇo* + *iti*] ascetic, recluse; **[√sam + aṇa]** |
