# Cittānupassanā

*Contemplation of Mind*

### 3 Cittānupassanā

*Contemplation of the mind*

**Kathañca pana, bhikkhave, bhikkhu citte cittānupassī viharati?**

**Literal:** How-and then, bhikkhus, [does] a-bhikkhu in-the-mind mind-contemplating dwell?  
**Faithful:** And how, bhikkhus, does a bhikkhu dwell contemplating the mind as mind?  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`kathañca`** | `(sandhi)` [*kathaṁ* (adv) how + *ca* (ind) and] and how?; **[kathaṁ + ca]** |
| **`pana`** | `(ind)` moreover, and so, but; **[pana]** |
| **`bhikkhave`** | `(masc voc pl)` bhikkhus, monks; **[√bhikkh + u + ave]** |
| **`bhikkhu`** | `(masc nom sg)` bhikkhu, monk; **[√bhikkh + u]** |
| **`citte`** | `(nt loc sg)` in the mind; **[√cit + ta]** |

| **`viharati`** | `(3rd sg pres act indic)` dwells, lives; **[vi + √har + a + ti]** |
