# Maggasaccaniddesa

*Exposition of the Truth of the Path*

### 4.5.4 Maggasaccaniddesa

*Exposition of the truth of the path*

**Katamañca, bhikkhave, dukkhanirodhagāminī paṭipadā ariyasaccaṁ?**

**Literal:** What-and, bhikkhus, [is the] suffering-cessation-leading way noble-truth?  
**Faithful:** And what, bhikkhus, is the noble truth of the way of practice leading to the cessation of suffering?  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`katamañca`** | `(sandhi)` [*katamaṁ* (interr pron nt nom sg) which?, what? + *ca* (ind) and] and what?; **[katamaṁ + ca]** |
| **`bhikkhave`** | `(masc voc pl)` bhikkhus, monks; **[√bhikkh + u + ave]** |
| **`dukkhanirodhagāminī`** | `(adj fem nom sg comp)` [agrees with *paṭipadā*] leading to the cessation of suffering; **[dukkha + nirodha + gāminī]** |
| ↳ **`dukkha`** | `(nt comp)` suffering, discomfort; **[√dukkh + a]** |
| ↳ **`nirodha`** | `(masc comp)` cessation, ending; **[ni + √rudh > rodh + a]** |
| ↳ **`gāminī`** | `(adj fem nom sg)` going, leading (to); **[√gam > gām + ī + inī]** |
| **`paṭipadā`** | `(fem nom sg)` [DPD idiom *dukkhanirodhagāminī paṭipadā ariyasaccaṁ*] way, way of practice; **[pati + √pad + ā]** |
| **`ariyasaccaṁ`** | `(nt nom sg comp)` noble truth; **[ariya + sacca]** |
| ↳ **`ariya`** | `(adj comp)` noble; **[ariya, no root in DPD]** |
| ↳ **`saccaṁ`** | `(nt nom sg)` truth; **[√as > sa + nta > santa > sat + ya]** |
