# Samudayasaccaniddesa

*Exposition of the Truth of the Origin*

### 4.5.2 Samudayasaccaniddesa

*Exposition of the truth of the origin*

**Katamañca, bhikkhave, dukkhasamudayaṁ ariyasaccaṁ?**

**Literal:** What-and, bhikkhus, [is the] suffering-origin noble-truth?  
**Faithful:** And what, bhikkhus, is the noble truth of the origin of suffering?  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`katamañca`** | `(sandhi)` [*katamaṁ* (interr pron nt nom sg) which?, what? + *ca* (ind) and] and what?; **[katamaṁ + ca]** |
| **`bhikkhave`** | `(masc voc pl)` bhikkhus, monks; **[√bhikkh + u + ave]** |
| **`dukkhasamudayaṁ`** | `(nt nom sg comp)` [masc in DPD; here neuter, agreeing with *ariyasaccaṁ*] origin of suffering, arising of suffering; **[dukkha + samudaya]** |
| ↳ **`dukkha`** | `(nt comp)` suffering; **[√dukkh + a]** |
| ↳ **`samudayaṁ`** | `(nt nom sg)` [masc in DPD] origin, arising; **[saṁ + ud + √i > ay + a]** |
| **`ariyasaccaṁ`** | `(nt nom sg comp)` noble truth; **[ariya + sacca]** |
| ↳ **`ariya`** | `(adj comp)` noble; **[ariya, no root in DPD]** |
| ↳ **`saccaṁ`** | `(nt nom sg)` truth; **[√as > sa + nta > santa > sat + ya]** |

**Yāyaṁ taṇhā ponobbhavikā nandīrāgasahagatā tatratatrābhinandinī,**

**Literal:** Which this craving, renewed-existence-producing, delight-passion-accompanied, there-there-delighting,  
**Faithful:** It is this craving, which leads to renewed existence, is accompanied by delight and passion, and takes delight now here, now there,  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`yāyaṁ`** | `(sandhi)` [*yā* (rel pron fem nom sg) + *ayaṁ* (dem pron fem nom sg)] which is this, that which; **[yā + ayaṁ]** |
| **`taṇhā`** | `(fem nom sg)` craving; **[√tas + ṇhā]** |
| **`ponobbhavikā`** | `(adj fem nom sg)` leading to renewed existence; **[puna > pono + bhava + ika]** |
| **`nandīrāgasahagatā`** | `(adj fem nom sg comp)` accompanied by delight and passion; **[nandī + rāga + sahagata]** |
| ↳ **`nandī`** | `(fem comp)` delight, enjoyment; **[√nand + ī]** |
| ↳ **`rāga`** | `(masc comp)` passion, lust; **[√raj > rag > rāg + a]** |
| ↳ **`sahagatā`** | `(adj fem nom sg)` accompanied (by), connected (with); **[saha + gata]** |
| **`tatratatrābhinandinī`** | `(adj fem nom sg comp)` delighting now here, now there; **[tatra + tatra + abhinandī]** |
| ↳ **`tatra`** | `(ind comp)` there; **[ta + tra]** |
| ↳ **`tatr'`** | `(ind comp)` [*tatra* before a vowel] there; **[ta + tra]** |
| ↳ **`ābhinandinī`** | `(adj fem nom sg)` [*a-* lengthened in sandhi] delighting (in), taking pleasure (in); **[abhi + √nand + ī + inī]** |
