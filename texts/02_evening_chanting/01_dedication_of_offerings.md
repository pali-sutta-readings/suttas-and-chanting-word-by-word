# Yo so bhagavā

*Dedication of Offerings*

**Yo so bhagavā arahaṁ sammāsambuddho**

**Literal:** Who that Blessed One, Arahant, Perfectly Self-Awakened One  
**Faithful:** To the Blessed One, the Arahant, the Perfectly Self-Awakened One;  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`yo`** | `(rel pron masc nom sg)` who, which; **[ya]** |
| **`so`** | `(dem pron masc nom sg)` that, he; **[ta]** |
| **`bhagavā`** | `(masc nom sg)` Blessed One, Fortunate One; **[√bhaj > bhag + a + vant]** |
| **`arahaṁ`** | `(masc nom sg)` Arahant, Worthy One; **[√arah + ant]** |
| **`sammāsambuddho`** | `(masc nom sg comp)` Perfectly Self-Awakened One; **[sammā + sambuddha]** |
| ↳ **`sammā`** | `(ind comp)` perfectly, rightly; **[sammā]** |
| ↳ **`sambuddho`** | `(masc nom sg)` self-awakened one; **[saṁ + √budh + ta]** |
