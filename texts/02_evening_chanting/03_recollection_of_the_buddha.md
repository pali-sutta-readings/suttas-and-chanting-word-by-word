# Buddhānussati

*Recollection of the Buddha*

**Handa mayaṁ buddhānussatinayaṁ karomase**

**Literal:** Come now, we [the] method of recollecting [the] Buddha let us make  
**Faithful:** Now let us chant the recollection of the Buddha.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`handa`** | `(interj)` come now, well then; **[handa]** |
| **`mayaṁ`** | `(1st pl nom)` we; **[ahaṁ]** |
| **`buddhānussatinayaṁ`** | `(masc acc sg comp)` method of recollecting the Buddha; **[buddha + anussati + naya]** |
| ↳ **`buddha`** | `(masc comp)` Buddha; **[√budh + ta]** |
| ↳ **`anussati`** | `(fem comp)` recollection; **[anu + √sar + ti]** |
| ↳ **`nayaṁ`** | `(masc acc sg)` method, way; **[√nī + a]** |
| **`karomase`** | `(1st pl pres mid imperat)` let us make, let us do; **[√kar + o + mase]** |

**Taṁ kho pana bhagavantaṁ evaṁ kalyāṇo kittisaddo abbhuggato**

**Literal:** That indeed now Blessed One thus good report of fame has gone up  
**Faithful:** Concerning that Blessed One, this good report of fame has spread:  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`taṁ`** | `(dem pron masc acc sg)` [acc of reference] concerning that, about him; **[ta]** |
| **`kho`** | `(ind)` indeed, truly; **[kho]** |
| **`pana`** | `(ind)` now, moreover; **[pana]** |
| **`bhagavantaṁ`** | `(masc acc sg)` Blessed One; **[√bhaj > bhag + a + vant]** |
| **`evaṁ`** | `(ind)` thus, in this way; **[eva + aṁ]** |
| **`kalyāṇo`** | `(masc nom sg)` good, fine, lovely; **[kalyāṇa, no root in DPD]** |
| **`kittisaddo`** | `(masc nom sg comp)` report of fame, good reputation; **[kitti + sadda]** |
| ↳ **`kitti`** | `(fem comp)` fame, renown; **[√kitt + i]** |
| ↳ **`saddo`** | `(masc nom sg)` report, sound; **[√sadd + a]** |
| **`abbhuggato`** | `(pp masc nom sg)` has spread, has gone up; **[abhi + ud + √gam + ta]** |

**Itipi so bhagavā arahaṁ sammāsambuddho**

**Literal:** Thus indeed he, [the] Blessed One, [is] Arahant, Perfectly Self-Awakened One

| Word | Analysis & Meaning |
| :--- | :--- |

| **`so`** | `(dem pron masc nom sg)` that, he; **[ta]** |
| **`bhagavā`** | `(masc nom sg)` Blessed One; **[√bhaj > bhag + a + vant]** |
| **`arahaṁ`** | `(masc nom sg)` Arahant, Worthy One; **[√arah + ant]** |
| **`sammāsambuddho`** | `(masc nom sg comp)` Perfectly Self-Awakened One; **[sammā + sambuddha]** |
| ↳ **`sammā`** | `(ind comp)` perfectly, rightly; **[sammā]** |
| ↳ **`sambuddho`** | `(masc nom sg)` self-awakened one; **[saṁ + √budh + ta]** |

**Anuttaro purisadamma-sārathi satthā deva-manussānaṁ buddho bhagavā'ti**

**Literal:** Unsurpassed trainer of persons to be tamed, teacher of devas and humans, Buddha, Blessed One — thus  
**Faithful:** the unsurpassed trainer of those who can be tamed, the teacher of devas and humans, the Buddha, the Blessed One."  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`anuttaro`** | `(adj masc nom sg)` unsurpassed, incomparable; **[na > an + ud + tara]** |
| **`purisadamma-sārathi`** | `(masc nom sg comp)` trainer of tameable persons; **[purisa + damma + sārathi]** |
| ↳ **`purisa`** | `(masc comp)` person, man; **[purisa, no root in DPD]** |
| ↳ **`damma`** | `(ptp comp)` to be tamed, tameable; **[√dam + ya]** |
| ↳ **`sārathi`** | `(masc nom sg)` trainer, charioteer; **[sa + ratha + i]** |
| **`satthā`** | `(masc nom sg)` teacher, master; **[√sās + tar]** |
| **`deva-manussānaṁ`** | `(masc gen pl comp)` of devas and humans; **[deva + manussa]** |
| ↳ **`deva`** | `(masc comp)` deva; **[√div > dev + a]** |
| ↳ **`manussānaṁ`** | `(masc gen pl)` of humans; **[manu + ssa]** |
| **`buddho`** | `(masc nom sg)` Buddha, Awakened One; **[√budh + ta]** |
| **`bhagavā`** | `(masc nom sg)` Blessed One; **[√bhaj > bhag + a + vant]** |
| **`'ti`** | `(ind)` [*iti* with *i-* elided] thus (closes the recollection); **[iti]** |
