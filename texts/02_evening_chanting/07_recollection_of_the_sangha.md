# Saṅghānussati

*Recollection of the Saṅgha*

**Handa mayaṁ saṅghānussatinayaṁ karomase**

**Literal:** Come now, we [the] method of recollecting [the] Saṅgha let us make  
**Faithful:** Now let us chant the recollection of the Saṅgha.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`handa`** | `(interj)` come now, well then; **[handa]** |
| **`mayaṁ`** | `(1st pl nom)` we; **[ahaṁ]** |
| **`saṅghānussatinayaṁ`** | `(masc acc sg comp)` method of recollecting the Saṅgha; **[saṅgha + anussati + naya]** |
| ↳ **`saṅgha`** | `(masc comp)` Saṅgha; **[saṁ + √ghaṭ + a]** |
| ↳ **`anussati`** | `(fem comp)` recollection; **[anu + √sar + ti]** |
| ↳ **`nayaṁ`** | `(masc acc sg)` method, way; **[√nī + a]** |
| **`karomase`** | `(1st pl pres mid imperat)` let us make, let us do; **[√kar + o + mase]** |
