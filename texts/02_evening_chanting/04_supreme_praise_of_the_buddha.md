# Buddhābhigīti

*Supreme Praise of the Buddha*

**Handa mayaṁ buddhābhigītiṁ karomase**

**Literal:** Come now, we [the] high song of praise of [the] Buddha let us make  
**Faithful:** Now let us chant the high praise of the Buddha.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`handa`** | `(interj)` come now, well then; **[handa]** |
| **`mayaṁ`** | `(1st pl nom)` we; **[ahaṁ]** |
| **`buddhābhigītiṁ`** | `(fem acc sg comp)` high song of praise of the Buddha; **[buddha + abhigīti]** |
| ↳ **`buddha`** | `(masc comp)` Buddha; **[√budh + ta]** |
| ↳ **`abhigītiṁ`** | `(fem acc sg)` high song, song of praise; **[abhi + √gā + ti]** |
| **`karomase`** | `(1st pl pres mid imperat)` let us make, let us do; **[√kar + o + mase]** |

**Buddh'vārahanta-varatādiguṇābhiyutto**

**Faithful:** The Buddha, endowed with such qualities as the excellence of an Arahant,  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`buddh'v-`** | `(masc nom sg)` [*buddho* before a vowel: *-o* > *-v*] Buddha, Awakened One; **[√budh + ta]** |
| **`ārahanta-varatādiguṇābhiyutto`** | `(pp masc nom sg comp)` endowed with qualities such as the excellence of an Arahant; **[arahanta + varatā + ādi + guṇa + abhiyutta]** |
| ↳ **`ārahanta`** | `(masc comp)` [*arahanta* with *a-* lengthened in sandhi] Arahant, Worthy One; **[√arah + ant]** |
| ↳ **`varatā`** | `(fem comp)` excellence, supremacy; **[vara (√var + a) + tā]** |
| ↳ **`ādi`** | `(masc comp)` beginning with, and so on; **[ādi, no root in DPD]** |
| ↳ **`guṇa`** | `(masc comp)` quality, virtue; **[guṇa, no root in DPD]** |
| ↳ **`abhiyutto`** | `(pp masc nom sg)` endowed with, engaged in; **[abhi + √yuj + ta]** |
