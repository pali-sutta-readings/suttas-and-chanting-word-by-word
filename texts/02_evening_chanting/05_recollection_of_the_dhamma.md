# Dhammānussati

*Recollection of the Dhamma*

**Handa mayaṁ dhammānussatinayaṁ karomase**

**Literal:** Come now, we [the] method of recollecting [the] Dhamma let us make  
**Faithful:** Now let us chant the recollection of the Dhamma.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`handa`** | `(interj)` come now, well then; **[handa]** |
| **`mayaṁ`** | `(1st pl nom)` we; **[ahaṁ]** |
| **`dhammānussatinayaṁ`** | `(masc acc sg comp)` method of recollecting the Dhamma; **[dhamma + anussati + naya]** |
| ↳ **`dhamma`** | `(masc comp)` Dhamma; **[√dhar + ma]** |
| ↳ **`anussati`** | `(fem comp)` recollection; **[anu + √sar + ti]** |
| ↳ **`nayaṁ`** | `(masc acc sg)` method, way; **[√nī + a]** |
| **`karomase`** | `(1st pl pres mid imperat)` let us make, let us do; **[√kar + o + mase]** |

**Svākkhāto bhagavatā dhammo**

**Literal:** Well proclaimed by [the] Blessed One [is the] Dhamma  
**Faithful:** "The Dhamma is well proclaimed by the Blessed One,  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`svākkhāto`** | `(adj masc nom sg)` well proclaimed, well taught; **[su > sv + ā + √khā + ta]** |
| **`bhagavatā`** | `(masc instr sg)` by the Blessed One; **[√bhaj > bhag + a + vant]** |
| **`dhammo`** | `(masc nom sg)` Dhamma, teaching; **[√dhar + ma]** |

**Sandiṭṭhiko akāliko ehipassiko**

**Literal:** Directly visible, timeless, inviting to come and see  
**Faithful:** visible here and now, timeless, inviting one to come and see,  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`sandiṭṭhiko`** | `(adj masc nom sg)` directly visible, evident here and now; **[saṁ + √dis + ti + ka]** |
| **`akāliko`** | `(adj masc nom sg)` timeless, immediate; **[na + √kal + a + ika]** |
| **`ehipassiko`** | `(masc nom sg comp)` inviting one to come and see, open to inspection; **[ehi + passa + ika]** |
| ↳ **`ehi`** | `(2nd sg pres act imperat)` come!; **[√i + a + hi]** |
| ↳ **`passa`** | `(2nd sg pres act imperat)` see!; **[√dis + a (passa)]** |

**Opanayiko paccattaṁ veditabbo viññūhī'ti**

**Literal:** Leading onward, personally to be known by [the] wise — thus  
**Faithful:** leading onward, to be experienced by the wise for themselves."  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`opanayiko`** | `(adj masc nom sg)` leading onward, leading towards [the goal]; **[upa + √nī + a + ika]** |
| **`paccattaṁ`** | `(adv)` personally, for oneself, individually; **[pati + atta + aṁ]** |
| **`veditabbo`** | `(ptp masc nom sg)` to be known, to be experienced; **[√vid + e + itabba]** |
| **`viññūhī`** | `(masc instr pl)` [*viññūhi* with final *-i* lengthened before *'ti*] by the wise, by the discerning; **[vi + √ñā + ū]** |
| **`'ti`** | `(ind)` [*iti* with *i-* elided] thus (closes the recollection); **[iti]** |
