# Arahaṁ sammāsambuddho

*Closing Homage*

**Arahaṁ sammāsambuddho bhagavā**

**Literal:** Arahant, Perfectly Self-Awakened One, Blessed One  
**Faithful:** The Blessed One is an Arahant, perfectly self-awakened.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`arahaṁ`** | `(masc nom sg)` Arahant, Worthy One; **[√arah + ant]** |
| **`sammāsambuddho`** | `(masc nom sg comp)` Perfectly Self-Awakened One; **[sammā + sambuddha]** |
| ↳ **`sammā`** | `(ind comp)` perfectly, rightly; **[sammā]** |
| ↳ **`sambuddho`** | `(masc nom sg)` self-awakened one; **[saṁ + √budh + ta]** |
| **`bhagavā`** | `(masc nom sg)` Blessed One; **[√bhaj > bhag + a + vant]** |

**Buddhaṁ bhagavantaṁ abhivādemi**

**Literal:** [The] Buddha, [the] Blessed One, I bow down to  
**Faithful:** I bow down to the Buddha, the Blessed One.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`buddhaṁ`** | `(masc acc sg)` Buddha, Awakened One; **[√budh + ta]** |
| **`bhagavantaṁ`** | `(masc acc sg)` Blessed One; **[√bhaj > bhag + a + vant]** |
| **`abhivādemi`** | `(1st sg pres caus act indic)` I bow down to, I pay high respect to; **[abhi + √vad + e + mi]** |

**Supaṭipanno bhagavato sāvakasaṅgho**

**Literal:** Practising well [is the] Blessed One's Saṅgha of disciples  
**Faithful:** The Saṅgha of the Blessed One's disciples practises well.  

| Word | Analysis & Meaning |
| :--- | :--- |
| **`supaṭipanno`** | `(masc nom sg)` practising well, going the right way; **[su + pati + √pad + na]** |
| **`bhagavato`** | `(masc gen sg)` of the Blessed One; **[√bhaj > bhag + a + vant]** |
| **`sāvakasaṅgho`** | `(masc nom sg comp)` Saṅgha of disciples; **[sāvaka + saṅgha]** |
| ↳ **`sāvaka`** | `(masc comp)` disciple; **[√su > sāv + aka]** |
| ↳ **`saṅgho`** | `(masc nom sg)` community, Saṅgha; **[saṁ + √ghaṭ + a]** |
